Тема 1. Элементы комбинаторики и основы теории вероятностей

1.1 Основные понятия комбинаторики

Комбинаторика — раздел математики, изучающий способы подсчёта количества комбинаций объектов.

Основной принцип Описание Пример
Правило суммы Если элемент A можно выбрать m способами, а элемент B — n способами, то выбрать A или B можно m + n способами Выбор напитка из 3 видов чая и 2 видов кофе → 5 вариантов
Правило произведения Если элемент A можно выбрать m способами, а элемент B — n способами, то выбрать пару (A, B) можно m × n способами Выбор напитка и десерта из 3 напитков и 4 десертов → 12 вариантов
Применение в ИТ: комбинаторика используется в криптографии, алгоритмах поиска, оценке сложности алгоритмов.

1.2 Перестановки, размещения, сочетания

Перестановки — упорядоченные наборы из всех n элементов.

Размещения — упорядоченные наборы из k элементов, выбранных из n.

Сочетания — неупорядоченные наборы из k элементов, выбранных из n .

Тип Формула Пример
Перестановки Pₙ = n! Сколькими способами можно расставить 5 книг на полке? 5! = 120
Размещения Aₙᵏ = n! / (n−k)! Сколько 3-значных чисел можно составить из 5 цифр? 5!/(5-3)! = 60
Сочетания Cₙᵏ = n! / (k!(n−k)!) Сколькими способами можно выбрать 3 книги из 5? C₅³ = 10
Важно: порядок важен для перестановок и размещений, но не важен для сочетаний.

1.3 Случайные события и операции над ними

Случайное событие — это исход, который может произойти или не произойти в результате эксперимента .

Тип события Описание Пример
Достоверное Происходит всегда При бросании кубика выпадет число от 1 до 6
Невозможное Не может произойти При бросании кубика выпадет 7
Случайное Может произойти или нет При бросании кубика выпадет 5
Операции над событиями:
  • Объединение (A ∪ B) — произошло A или B
  • Пересечение (A ∩ B) — произошло A и B
  • Дополнение (¬A) — произошло не A

1.4 Классическое и статистическое определение вероятности

Классическое определение: вероятность события A равна отношению числа благоприятных исходов к общему числу равновозможных исходов .

P(A) = m / n, где m — число благоприятных исходов, n — общее число исходов.

Статистическое определение: вероятность события A — это предел относительной частоты его появления при большом числе испытаний.
Пример: Вероятность выпадения орла при подбрасывании монеты = 1/2 = 0.5.

1.5 Геометрическая вероятность

Геометрическая вероятность — это вероятность попадания точки в область, определяемая отношением мер областей .

Формула: P(A) = (мера области A) / (мера всей области)

Пример: Какова вероятность, что точка, брошенная в круг радиуса R, попадёт в меньший круг радиуса r?

P = (πr²) / (πR²) = r² / R²

1.6 Теоремы сложения и умножения вероятностей

Теорема Формула Пример
Сложения для несовместных P(A ∪ B) = P(A) + P(B) Вероятность выпадения 1 или 2 на кубике = 1/6 + 1/6 = 1/3
Сложения для совместных P(A ∪ B) = P(A) + P(B) − P(A ∩ B) P(число > 3 или чётное) = 1/2 + 1/2 − 1/3 = 2/3
Умножения для независимых P(A ∩ B) = P(A) × P(B) Вероятность выпадения орла дважды = 1/2 × 1/2 = 1/4
Умножения общая P(A ∩ B) = P(A) × P(B|A) Вероятность вытянуть два туза подряд из колоды

1.7 Условная вероятность и независимость событий

Условная вероятность P(B|A) — это вероятность события B при условии, что событие A уже произошло .

Формула: P(B|A) = P(A ∩ B) / P(A), если P(A) > 0

Независимые события: A и B независимы, если P(B|A) = P(B) .

Пример: Вероятность выпадения орла при втором подбрасывании не зависит от результата первого.

1.8 Формула полной вероятности

Формула полной вероятности позволяет найти вероятность события A, если известны вероятности гипотез H₁, H₂, ..., Hₙ и условные вероятности A при каждой гипотезе .

Формула: P(A) = Σ P(Hᵢ) × P(A|Hᵢ)

Пример: На складе 3 поставщика. Вероятность брака у каждого: 1%, 2%, 3%. Доли поставок: 50%, 30%, 20%. Какова общая вероятность брака?

P = 0.5×0.01 + 0.3×0.02 + 0.2×0.03 = 0.005 + 0.006 + 0.006 = 0.017 = 1.7%

1.9 Формула Байеса

Формула Байеса позволяет пересчитать вероятности гипотез после того, как событие A произошло .

Формула: P(Hᵢ|A) = P(Hᵢ) × P(A|Hᵢ) / P(A)
Применение в ИТ: спам-фильтры, диагностика систем, машинное обучение (наивный байесовский классификатор).

1.10 Схема Бернулли. Формула Бернулли

Схема Бернулли — это последовательность n независимых испытаний, в каждом из которых событие A происходит с вероятностью p .

Формула Бернулли: Pₙ(k) = Cₙᵏ × pᵏ × (1−p)ⁿ⁻ᵏ

где k — число успехов в n испытаниях.

Пример: Вероятность того, что при 5 подбрасываниях монеты орёл выпадет ровно 3 раза:

P₅(3) = C₅³ × (1/2)³ × (1/2)² = 10 × 1/8 × 1/4 = 10/32 = 0.3125

Тема 2. Случайные величины и их распределения

2.1 Понятие случайной величины

Случайная величина — это величина, которая в результате эксперимента принимает одно из множества значений, причём заранее неизвестно, какое именно .

Тип Описание Пример
Дискретная Принимает конечное или счётное множество значений Количество выпавших орлов при подбрасывании монеты
Непрерывная Принимает значения из непрерывного промежутка Рост человека, время ожидания

2.2 Дискретные случайные величины

Ряд распределения дискретной случайной величины — это соответствие между значениями и их вероятностями .

Свойства ряда распределения:
  • Σ Pᵢ = 1 (сумма всех вероятностей равна 1)
  • Pᵢ ≥ 0 для всех i

Пример: Бросание кубика. Ряд распределения: X = {1, 2, 3, 4, 5, 6}, P = {1/6, 1/6, 1/6, 1/6, 1/6, 1/6}

2.3 Непрерывные случайные величины

Непрерывная случайная величина описывается плотностью распределения вероятностей .

Свойства плотности f(x):
  • f(x) ≥ 0 для всех x
  • ∫ f(x) dx = 1 (интеграл по всей области равен 1)
  • P(a < X < b) = ∫ₐᵇ f(x) dx

2.4 Функция распределения и её свойства

Функция распределения F(x) = P(X < x) — это вероятность того, что случайная величина X примет значение меньше x .

Свойства F(x):
  • 0 ≤ F(x) ≤ 1
  • F(x) — неубывающая функция
  • lim F(x) = 0 при x → −∞
  • lim F(x) = 1 при x → +∞
  • P(a < X < b) = F(b) − F(a)

2.5 Плотность распределения вероятностей

Плотность распределения f(x) = F'(x) — это производная функции распределения (для непрерывных величин) .

Связь: F(x) = ∫ f(t) dt (от −∞ до x)

Пример: Нормальное распределение имеет плотность:

f(x) = (1/√(2πσ²)) × exp(−(x−μ)²/(2σ²))

2.6 Математическое ожидание

Математическое ожидание — это среднее значение случайной величины .

Тип Формула
Дискретная M(X) = Σ xᵢ × P(xᵢ)
Непрерывная M(X) = ∫ x × f(x) dx
Свойства M(X):
  • M(c) = c (константа)
  • M(cX) = c×M(X)
  • M(X+Y) = M(X) + M(Y)
  • Для независимых: M(XY) = M(X)×M(Y)

2.7 Дисперсия и среднее квадратическое отклонение

Дисперсия D(X) — мера разброса случайной величины относительно математического ожидания .

Тип Формула
Дискретная D(X) = Σ (xᵢ − M(X))² × P(xᵢ)
Непрерывная D(X) = ∫ (x − M(X))² × f(x) dx
Упрощённая D(X) = M(X²) − (M(X))²
Среднее квадратическое отклонение: σ(X) = √D(X)

2.8 Биномиальное распределение

Биномиальное распределение — распределение числа успехов в схеме Бернулли .

Параметры: n (число испытаний), p (вероятность успеха)

P(X = k) = Cₙᵏ × pᵏ × (1−p)ⁿ⁻ᵏ

Характеристики:
  • M(X) = n × p
  • D(X) = n × p × (1−p)

2.9 Распределение Пуассона

Распределение Пуассона — предельный случай биномиального распределения при n → ∞, p → 0, np = λ .

Формула: P(X = k) = (λᵏ / k!) × e⁻λ
Применение в ИТ: моделирование количества запросов на сервер, числа ошибок в коде, трафика в сети.

2.10 Нормальное распределение (распределение Гаусса)

Нормальное распределение — это наиболее распространённое непрерывное распределение .

Плотность: f(x) = (1/(σ√(2π))) × exp(−(x−μ)²/(2σ²))
Применение в ИТ: анализ производительности, обработка сигналов, машинное обучение, статистический анализ данных.
Характеристика Значение
Математическое ожидание μ (среднее)
Дисперсия σ²
Правило трёх сигм P(μ−3σ < X < μ+3σ) ≈ 0.997

Тема 3. Предельные теоремы и закон больших чисел

3.1 Неравенство Чебышева

📐 Основная формула

P(|X − M(X)| ≥ ε) ≤ D(X) / ε²

Неравенство Чебышева даёт оценку вероятности того, что случайная величина отклонится от своего математического ожидания не менее чем на заданную величину ε.

💡 Смысл неравенства
  • Даёт верхнюю границу вероятности больших отклонений
  • Работает для любых распределений
  • Чем больше дисперсия, тем выше вероятность отклонения
  • Чем больше ε, тем меньше вероятность отклонения
📝 Следствие

P(|X − M(X)| < ε) ≥ 1 − D(X) / ε²

Вероятность того, что отклонение будет меньше ε, не менее указанной величины.
Обозначение Описание
X Случайная величина
M(X) Математическое ожидание
D(X) Дисперсия
ε Допустимое отклонение (ε > 0)
📌 Пример

Пусть D(X) = 1, ε = 3. Тогда:

P(|X − M(X)| ≥ 3) ≤ 1/9 ≈ 0.111

Вероятность отклонения более чем на 3 не превышает 11.1%.
⚠️ Важно

Оценка может быть грубой. Для нормального распределения реальная вероятность значительно меньше.

3.2 Закон больших чисел

📐 Теорема Чебышева

Если X₁, X₂, ..., Xₙ — независимые случайные величины с конечными дисперсиями, ограниченными одной константой C, то:

(1/n)ΣXᵢ → M(X) при n → ∞ (по вероятности)

Закон больших чисел — фундаментальный результат, утверждающий, что среднее арифметическое большого числа случайных величин сходится к их математическому ожиданию.

💡 Суть закона
  • При увеличении числа испытаний относительная частота события стремится к его вероятности
  • Среднее арифметическое стремится к математическому ожиданию
  • Ошибка уменьшается пропорционально 1/√n
Форма закона Формулировка
Теорема Бернулли Частота успеха → p (вероятность успеха)
Теорема Чебышева Среднее арифметическое → M(X)
Усиленный ЗБЧ Сходимость почти наверное (не только по вероятности)
📌 Пример

При подбрасывании монеты 10 раз доля орлов может быть 0.7 или 0.3.

При 1000 бросках доля орлов будет ≈ 0.5.

При 1 000 000 бросках ошибка будет менее 0.001.

💻 Применение в ИТ
  • Метод Монте-Карло — численное интегрирование и моделирование
  • Оценка качества генераторов случайных чисел
  • Машинное обучение — оценка параметров на больших данных
  • Статистическое тестирование — проверка гипотез

3.3 Центральная предельная теорема

📐 Формулировка ЦПТ

Пусть X₁, X₂, ..., Xₙ — независимые одинаково распределённые случайные величины с M(Xᵢ) = μ и D(Xᵢ) = σ². Тогда:

Zₙ = (ΣXᵢ − nμ) / (σ√n) → N(0, 1) при n → ∞

Центральная предельная теорема (ЦПТ) — один из важнейших результатов теории вероятностей. Она объясняет, почему нормальное распределение так часто встречается в природе и статистике.

💡 Ключевые идеи
  • Сумма большого числа случайных величин ≈ нормальное распределение
  • Исходные распределения могут быть любыми (не обязательно нормальными)
  • Сходимость тем быстрее, чем симметричнее исходное распределение
  • Дисперсия суммы растёт линейно с n
Параметр Обозначение Описание
Сумма Sₙ = ΣXᵢ Сумма n случайных величин
Математическое ожидание суммы nμ Среднее значение суммы
СКО суммы σ√n Стандартное отклонение суммы
Нормированная сумма Zₙ Приводит к стандартному нормальному распределению
📌 Пример

Сумма 100 бросков кубика (равномерное распределение) имеет распределение, близкое к нормальному с параметрами:

  • μ = 3.5 (среднее одного броска)
  • σ² ≈ 2.917 (дисперсия одного броска)
  • S₁₀₀ ≈ N(350, 291.7)
  • Z₁₀₀ = (S₁₀₀ − 350) / √291.7 ≈ N(0, 1)
💻 Применение в ИТ
  • Машинное обучение — обоснование использования нормального распределения
  • Статистический вывод — построение доверительных интервалов
  • Обработка сигналов — анализ шумов
  • А/B-тестирование — проверка гипотез

3.4 Теоремы Муавра-Лапласа

Теоремы Муавра-Лапласа — это частный случай ЦПТ для схемы Бернулли. Они позволяют приближённо вычислять вероятности для больших n.

Локальная теорема

Pₙ(k) ≈ (1/√(npq)) × φ(x)

где x = (k − np) / √(npq)

φ(x) = (1/√(2π)) × e^(−x²/2)

Применяется для нахождения вероятности конкретного значения k.
Интегральная теорема

P(k₁ < k < k₂) ≈ Φ(x₂) − Φ(x₁)

где x = (k − np) / √(npq)

Φ(x) = (1/√(2π)) ∫₀ˣ e^(−t²/2) dt

Применяется для нахождения вероятности попадания в интервал.
💡 Условия применения
  • n должно быть достаточно большим (обычно n > 30)
  • npq должно быть не слишком малым (обычно npq > 10)
  • Чем больше n, тем точнее приближение
Параметр Обозначение Описание
n — Число испытаний
p — Вероятность успеха
q 1 − p Вероятность неудачи
k — Число успехов
np — Математическое ожидание
√(npq) — Стандартное отклонение
📌 Пример

Вероятность того, что при 100 бросках монеты орёл выпадет от 45 до 55 раз.

Точное значение (по формуле Бернулли) ≈ 0.7286

По интегральной теореме Муавра-Лапласа:

  • np = 50, √(npq) = 5
  • x₁ = (45 − 50)/5 = −1
  • x₂ = (55 − 50)/5 = 1
  • P ≈ Φ(1) − Φ(−1) = 0.3413 − (−0.3413) = 0.6826
⚠️ Поправка на непрерывность

Для повышения точности при использовании интегральной теоремы применяют поправку Йейтса:

P(k₁ ≤ k ≤ k₂) ≈ Φ((k₂ + 0.5 − np)/√(npq)) − Φ((k₁ − 0.5 − np)/√(npq))

3.5 Сходимость по вероятности и по распределению

В теории вероятностей существует несколько видов сходимости случайных величин. Рассмотрим два основных типа.

Сходимость по вероятности

Xₙ → X (по вероятности)

Если ∀ε > 0:

P(|Xₙ − X| ≥ ε) → 0 при n → ∞

Вероятность того, что Xₙ отличается от X более чем на ε, стремится к нулю.
Сходимость по распределению

Xₙ → X (по распределению)

Если во всех точках непрерывности F(x):

Fₙ(x) → F(x) при n → ∞

Функции распределения сходятся к функции распределения X.
Характеристика По вероятности По распределению
Сила сходимости Более сильная Более слабая
Что сходится Значения случайных величин Закон распределения
Пример Закон больших чисел Центральная предельная теорема
Запись Xₙ → X (p) Xₙ → X (d)
💡 Важные соотношения
  • Из сходимости по вероятности следует сходимость по распределению
  • Обратное неверно в общем случае
  • Если предел — константа, то эти виды сходимости эквивалентны
📌 Примеры
  • Закон больших чисел: (1/n)ΣXᵢ → μ по вероятности
  • ЦПТ: Zₙ → N(0, 1) по распределению

3.6 Цепи Маркова (общее понятие)

📐 Марковское свойство

P(Xₙ = xₙ | Xₙ₋₁ = xₙ₋₁, ..., X₀ = x₀) = P(Xₙ = xₙ | Xₙ₋₁ = xₙ₋₁)

Цепь Маркова — это последовательность случайных событий, в которой вероятность каждого события зависит только от предыдущего состояния.

💡 Ключевые понятия
  • Состояние — возможное значение цепи в данный момент
  • Переход — изменение состояния
  • Матрица переходов — вероятности перехода между состояниями
  • Начальное распределение — распределение в момент t = 0
Тип цепи Описание Пример
Дискретная Конечное или счётное множество состояний Погода (солнечно/дождливо)
Непрерывная Континуум состояний Цена актива
Однородная Вероятности не зависят от времени Классическая цепь Маркова
Неоднородная Вероятности зависят от времени Сезонные изменения
📌 Пример

Прогноз погоды: если сегодня солнечно, то завтра с вероятностью 0.8 будет солнечно и с вероятностью 0.2 дождливо. Если сегодня дождливо, то завтра с вероятностью 0.6 будет дождливо и с вероятностью 0.4 солнечно.

Матрица переходов: [[0.8, 0.2], [0.4, 0.6]]

💻 Применение в ИТ
  • PageRank — алгоритм ранжирования страниц Google
  • Обработка текста — генерация текста, распознавание речи
  • Моделирование очередей — анализ производительности систем
  • Финансовое моделирование — кредитные рейтинги
  • Биоинформатика — анализ последовательностей ДНК

3.7 Случайные процессы

Случайный процесс — это семейство случайных величин X(t), зависящих от параметра t (обычно времени).

💡 Классификация случайных процессов
  • По множеству значений: дискретные и непрерывные
  • По множеству параметров: дискретное и непрерывное время
  • По зависимости: с независимыми приращениями, марковские
  • По стационарности: стационарные и нестационарные
Тип процесса Описание Пример
Процесс Пуассона Считает случайные события во времени Количество вызовов на станцию
Броуновское движение Непрерывный процесс с независимыми приращениями Движение частиц в жидкости
Процесс гибели и размножения Изменение численности популяции Рост популяции бактерий
Винеровский процесс Математическая модель броуновского движения Моделирование цен на бирже
📌 Пример

Пуассоновский процесс с интенсивностью λ = 2 (в среднем 2 события в минуту).

Вероятность ровно k событий за время t: P(N(t) = k) = (λt)ᵏ / k! × e^(−λt)

  • Обслуживание очередей — планирование ресурсов
  • Обработка сигналов — фильтрация шумов
  • Финансовое моделирование — прогнозирование курсов

3.8 Характеристические функции

📐 Определение

φ(t) = M(e^(itX)) = ∫ e^(itx) f(x) dx

Характеристическая функция — это преобразование Фурье плотности распределения. Она полностью определяет распределение случайной величины.

💡 Свойства
  • Однозначность: однозначно определяет распределение
  • Существование: существует для всех распределений
  • Моменты: M(Xᵏ) = (−i)ᵏ φ⁽ᵏ⁾(0)
  • Сумма: φₓ₊ᵧ(t) = φₓ(t) × φᵧ(t) для независимых X и Y
  • Сходимость: φₙ(t) → φ(t) ⇔ Xₙ → X (по распределению)
Распределение Характеристическая функция
Нормальное N(0, 1) φ(t) = e^(−t²/2)
Нормальное N(μ, σ²) φ(t) = e^(iμt − σ²t²/2)
Пуассона Pois(λ) φ(t) = e^(λ(e^(it) − 1))
Биномиальное Bin(n, p) φ(t) = (1 − p + p e^(it))ⁿ
Равномерное U(a, b) φ(t) = (e^(itb) − e^(ita)) / (it(b−a))
Экспоненциальное Exp(λ) φ(t) = λ / (λ − it)
📌 Пример использования

Доказательство ЦПТ с помощью характеристических функций:

φ_Zₙ(t) → e^(−t²/2), что соответствует стандартному нормальному распределению.

3.9 Условные математические ожидания

📐 Определение

M(X|Y = y) = ∫ x × f(x|y) dx — условное математическое ожидание X при условии Y = y

Условное математическое ожидание обобщает понятие условной вероятности на случайные величины.

💡 Свойства
  • Линейность: M(aX + bY | Z) = a M(X|Z) + b M(Y|Z)
  • Свойство башни: M(M(X|Y)) = M(X)
  • Независимость: если X и Y независимы, то M(X|Y) = M(X)
  • Монотонность: если X ≤ Y, то M(X|Z) ≤ M(Y|Z)
Случай Условное математическое ожидание
Дискретные величины M(X|Y=y) = Σ x × P(X=x|Y=y)
Непрерывные величины M(X|Y=y) = ∫ x × f(x|y) dx
Условная плотность f(x|y) = f(x,y) / f(y)
📌 Пример

Пусть X и Y имеют двумерное нормальное распределение с коэффициентом корреляции ρ.

M(X|Y=y) = μ_X + ρ × σ_X/σ_Y × (y − μ_Y)

💻 Применение в ИТ
  • Машинное обучение — прогнозирование на основе признаков
  • Фильтрация — оценка состояния систем
  • Эконометрика — моделирование зависимостей

Центральная предельная теорема

  • Проверка гипотез — z-критерий, t-критерий
  • Параметрическая статистика — нормальная аппроксимация

💡 Ключевые области применения

  • Финансы: оценка рисков, моделирование цен
Задача Применяемая теорема Пример

Проверка гипотезы о среднем Центральная предельная теорема z-тест, t-тест
Оценка вероятности Закон больших чисел Частота отказов системы
Моделирование сложных систем Закон больших чисел Метод Монте-Карло
Анализ аномалий Неравенство Чебышева Обнаружение выбросов
📌 Практический пример

Пусть мы измеряем время загрузки страницы (в мс). По ЦПТ:

  • Среднее время: μ
  • СКО: σ
  • Для n = 100 измерений среднее ≈ N(μ, σ²/100)
  • 95% доверительный интервал: x̄ ± 1.96 × σ/√100
🚀 Практические рекомендации

  • Учитывайте зависимость данных (независимость — важное условие)

Тема 4. Элементы математической статистики

4.1 Генеральная совокупность и выборка

Генеральная совокупность — все объекты, подлежащие изучению .

Выборка — часть объектов, отобранных для исследования .

Требования к выборке:
  • Репрезентативность — выборка должна отражать свойства генеральной совокупности
  • Случайность — каждый элемент должен иметь равную вероятность попасть в выборку

4.2 Вариационные ряды и гистограммы

Вариационный ряд — упорядоченная последовательность выборочных значений .

Элемент Описание
Дискретный ряд Значения и их частоты
Интервальный ряд Группировка данных по интервалам
Гистограмма Визуализация интервального ряда
Полигон частот График частот дискретного ряда

4.3 Числовые характеристики выборки

Характеристика Формула
Выборочное среднее x̄ = (1/n) Σ xᵢ
Выборочная дисперсия s² = (1/(n−1)) Σ (xᵢ − x̄)²
Выборочное СКО s = √s²
Мода Наиболее часто встречающееся значение
Медиана Среднее значение в упорядоченном ряду

4.4 Точечные оценки параметров

Свойства хороших оценок:
  • Несмещённость — M(θ̂) = θ
  • Состоятельность — θ̂ → θ при n → ∞
  • Эффективность — минимальная дисперсия среди всех оценок

Пример: Выборочное среднее — несмещённая и состоятельная оценка для математического ожидания .

4.5 Метод моментов

Метод моментов — метод оценивания параметров, основанный на приравнивании теоретических и выборочных моментов .

Алгоритм:
  1. Вычислить первые k выборочных моментов
  2. Записать теоретические моменты как функции параметров
  3. Приравнять и решить систему уравнений

4.6 Метод максимального правдоподобия

Метод максимального правдоподобия (ММП) — один из наиболее распространённых методов оценивания .

Суть: Найти параметры, при которых вероятность наблюдать данную выборку максимальна.

Функция правдоподобия: L(θ) = Π f(xᵢ; θ)

Применение в ИТ: обучение моделей машинного обучения, оценка параметров распределений.

4.7 Доверительные интервалы

Доверительный интервал — интервал, который с заданной вероятностью (уровнем доверия) покрывает истинное значение параметра .

Доверительный интервал для среднего при известной дисперсии:

x̄ ± z(α/2) × σ/√n

Пример: При n = 100, x̄ = 50, σ = 10, доверительный интервал на 95%:

50 ± 1.96 × 10/√100 = 50 ± 1.96 = [48.04, 51.96]

4.8 Проверка статистических гипотез

Статистическая гипотеза — предположение о параметрах распределения .

Термин Описание

Альтернативная гипотеза H₁ Предположение, принимаемое при отклонении H₀
Ошибка I рода Отклонить H₀, когда она верна
Ошибка II рода Принять H₀, когда она ложна
Уровень значимости α Вероятность ошибки I рода
p-значение Минимальный уровень значимости, при котором H₀ отклоняется
Применение в ИТ: A/B-тестирование, анализ производительности, проверка качества ПО.
