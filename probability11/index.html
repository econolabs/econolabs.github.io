11. Нормальное распределение (Normal Distribution)

1. Что такое нормальное распределение?

  • Непрерывное распределение вероятностей, симметричное и колоколообразное.
  • Многие реальные переменные (рост, вес, результаты тестов) приблизительно нормально распределены.
  • Полностью описывается двумя параметрами: средним (μ) и стандартным отклонением (σ).

2. Плотность вероятности (PDF)

$f(x)=\dfrac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
  • μ: среднее (центр распределения)
  • σ: стандартное отклонение (разброс)
  • $X \sim N(\mu, \sigma^2)$
  • f(x) даёт относительную плотность вероятности в точке x.

3. Форма нормального распределения

  • Симметрично относительно среднего. Среднее = Медиана = Мода = μ
  • Общая площадь под кривой = 1
  • С ростом σ кривая становится более плоской и широкой.

4. Эмпирическое правило (правило 68-95-99.7)

5. Стандартизация (Z-оценка, Z-Score)

  • Любое нормальное распределение можно преобразовать в стандартное нормальное N(0, 1) с помощью Z-оценки.
$Z = \dfrac{X-\mu}{\sigma}$
  • Если $X \sim N(\mu,\sigma^2)$, то $Z \sim N(0,1)$.
  • Используйте Z-таблицу для нахождения вероятностей.

6. Пример с Z-таблицей

Найдите $P(X \le 70)$ для $X \sim N(60, 10^2)$.

Решение:

  • $Z = \dfrac{70-60}{10} = 1$
  • По Z-таблице $P(Z \le 1) = 0.8413$

Итак, $P(X \le 70) = 0.8413$

7. Нахождение вероятностей

  • $P(X \le a) = P\left(Z \le \dfrac{a-\mu}{\sigma}\right)$
  • $P(X \ge a) = 1 - P(X \le a)$
  • $P(a \le X \le b) = P(Z_1 \le Z \le Z_2)$
  • где $Z_1 = \dfrac{a-\mu}{\sigma}$, $Z_2 = \dfrac{b-\mu}{\sigma}$

8. Пример — Рост

Рост людей распределён нормально с μ = 170 см, σ = 10 см. Найдите вероятность того, что рост человека находится между 160 см и 180 см.

Решение:

  • $Z_1 = \dfrac{160-170}{10} = -1$
  • $Z_2 = \dfrac{180-170}{10} = 1$

$P(160 \le X \le 180) = P(-1 \le Z \le 1) = 0.8413 - 0.1587 = 0.6826 \, (\approx 68.26\%)$
