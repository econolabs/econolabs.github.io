Тема 1. Введение в информационные технологии

1.1 Понятие и классификация информационных технологий

Информационная технология (ИТ) — это совокупность методов, процессов и программно-технических средств, направленных на сбор, обработку, хранение и передачу информации.

Тип ИТ Описание Пример
Офисные ИТ Работа с документами, таблицами, презентациями Microsoft Office, Google Workspace
Коммуникационные ИТ Передача информации, связь Email, мессенджеры, видеоконференции
Управленческие ИТ Поддержка принятия решений, управление ERP, CRM, BI-системы
Аналитические ИТ Обработка данных, анализ, прогнозирование Data Mining, Big Data, AI
Безопасные ИТ Защита информации, криптография SSL, VPN, ЭЦП

1.2 Эволюция информационных технологий

Этап Период Характеристика
1 1940-1960 Мейнфреймы, обработка данных на больших компьютерах
2 1960-1980 Появление персональных компьютеров, развитие ПО
3 1980-1990 Сетевые технологии, интернет, клиент-сервер
4 1990-2000 Всемирная паутина, электронная коммерция, мобильные технологии
5 2000-2010 Облачные технологии, социальные сети, Big Data
6 2010-н.в. Искусственный интеллект, блокчейн, IoT, квантовые вычисления

1.3 Цифровая трансформация

Цифровая трансформация — это процесс внедрения цифровых технологий для изменения бизнес-процессов, культуры и клиентского опыта.

Ключевые направления:
  • Автоматизация — замена ручного труда машинным
  • Данные — сбор и анализ информации для принятия решений
  • Омниканальность — единый клиентский опыт во всех каналах
  • Инновации — новые бизнес-модели и продукты

1.4 Облачные технологии (Cloud Computing)

Облачные вычисления — это модель предоставления вычислительных ресурсов через интернет.

Модель Расшифровка Описание Пример
IaaS Infrastructure as a Service Предоставление инфраструктуры (серверы, хранилища) Amazon EC2, Google Compute Engine
PaaS Platform as a Service Платформа для разработки и развертывания приложений Google App Engine, Heroku
SaaS Software as a Service Готовые приложения, доступные через браузер Google Docs, Salesforce, Zoom
FaaS Function as a Service Бессерверные вычисления (Serverless) AWS Lambda, Google Cloud Functions

1.5 Большие данные (Big Data)

Big Data — это большие объёмы данных, которые невозможно обработать традиционными методами.

5V Big Data:
  • Volume — объём (терабайты, петабайты)
  • Velocity — скорость (данные поступают в реальном времени)
  • Variety — разнообразие (структурированные, неструктурированные)
  • Veracity — достоверность (качество данных)
  • Value — ценность (извлечение полезной информации)
Инструмент Назначение
Hadoop Распределённое хранение и обработка данных
Spark Обработка больших данных в реальном времени
Kafka Потоковая передача данных
Elasticsearch Поиск и аналитика в реальном времени

1.6 Искусственный интеллект (Artificial Intelligence)

Искусственный интеллект (ИИ) — это область информатики, занимающаяся созданием систем, способных выполнять задачи, требующие человеческого интеллекта.

Тип ИИ Описание Пример
Узкий ИИ Выполнение одной задачи Голосовые ассистенты (Siri, Alexa)
Общий ИИ Выполнение любых интеллектуальных задач Пока не реализован (AGI)
Суперинтеллект ИИ, превосходящий человеческий интеллект Гипотетическая концепция
Направления AI: NLP (обработка языка), компьютерное зрение, робототехника, рекомендательные системы.

1.7 Машинное обучение (Machine Learning)

Машинное обучение — это подмножество ИИ, позволяющее системам обучаться на данных без явного программирования.

Тип обучения Описание Пример
С учителем Обучение на размеченных данных Классификация изображений, регрессия
Без учителя Обучение на неразмеченных данных Кластеризация, поиск аномалий
С подкреплением Обучение через вознаграждение Игры, робототехника
Глубокое обучение Обучение с использованием нейронных сетей Распознавание лиц, NLP

1.8 Криптография и безопасность

Криптография — это наука о методах шифрования и защиты информации.

Тип шифрования Описание Пример
Симметричное Один ключ для шифрования и расшифровки AES, DES
Асимметричное Пара ключей (публичный и приватный) RSA, ECC
Хеширование Преобразование данных в фиксированную длину SHA-256, MD5
Квантовая криптография Использование квантовых эффектов Квантовое распределение ключей
Применение: SSL/TLS, электронная подпись, VPN, шифрование дисков.

1.9 Блокчейн и распределённые реестры

Блокчейн — это распределённая база данных, состоящая из цепочки блоков, защищённых криптографией.

Ключевые свойства:
  • Децентрализация — нет единого центра управления
  • Неизменность — данные нельзя изменить задним числом
  • Прозрачность — все транзакции видны участникам
  • Безопасность — защита криптографией
Тип блокчейна Описание Пример
Публичный Открытый для всех Bitcoin, Ethereum
Приватный Доступ только для авторизованных Корпоративные блокчейны
Консорциальный Группа организаций Hyperledger, R3 Corda

1.10 Интернет вещей (Internet of Things, IoT)

Интернет вещей — это сеть физических объектов, оснащённых датчиками и подключённых к интернету.

Область применения Примеры
Умный дом Термостаты, освещение, камеры
Умный город Умные фонари, парковки, мониторинг воздуха
Промышленность Предиктивное обслуживание, мониторинг оборудования
Здравоохранение Носимые устройства, удалённый мониторинг
Сельское хозяйство Умные теплицы, мониторинг почвы

4.2 Электронная подпись (ЭП)

Электронная подпись (ЭП) — это реквизит документа, подтверждающий авторство и неизменность информации.

Вид ЭП Юридическая сила Применение
Простая Для внутреннего документооборота Логин/пароль, SMS-код
Неквалифицированная Для обмена с контрагентами Корпоративный документооборот
Квалифицированная (КЭП) Приравнена к собственноручной подписи Госзакупки, судебные дела, налоговая
КЭП выдается только удостоверяющими центрами, аккредитованными Минцифры.

Смарт-контракт — это программируемый контракт, который автоматически исполняется при выполнении условий.

Платформа Особенности

Tezos Самообновляемый блокчейн
Применение: финтех, логистика, страхование, голосование, нотариат.

4.9 Тренды и будущее информационных технологий

Ключевые тренды:
  • AGI (Artificial General Intelligence) — создание ИИ на уровне человека
  • Квантовые вычисления — решение задач, недоступных классическим компьютерам
