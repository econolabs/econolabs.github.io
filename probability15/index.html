15. Логистическая регрессия (Logistic Regression)

1. Что такое логистическая регрессия?

  • Алгоритм классификации для предсказания вероятности бинарного исхода (0 или 1).
  • Моделирует связь между входными признаками (X) и вероятностью целевой переменной (Y).
  • Использует сигмоидную функцию для преобразования линейного выхода в вероятность от 0 до 1.
  • Широко применяется в реальных задачах: обнаружение спама, диагностика заболеваний, выявление мошенничества и т.д.

2. Уравнение модели

$P(Y{=}1|X) = \dfrac{1}{1+e^{-(\beta_0+\beta_1 X)}}$
  • $\beta_0$: свободный член (intercept) — значение при X = 0
  • $\beta_1$: коэффициент (влияние X)
  • $e$: число Эйлера (≈ 2.718)
  • Выход — вероятность от 0 до 1.

3. Сигмоидная функция

$\sigma(z) = \dfrac{1}{1+e^{-z}}$
  • Преобразует любое действительное значение в вероятность от 0 до 1.
  • При большом положительном z → вероятность ≈ 1
  • При большом отрицательном z → вероятность ≈ 0

4. Разделяющая граница

При пороге 0.5:

  • Если $P(Y{=}1) \ge 0.5$ → прогнозируем класс 1
  • Если $P(Y{=}1) < 0.5$ → прогнозируем класс 0

5. Обучение (оценка параметров)

  • Параметры ($\beta_0, \beta_1$) находятся методом максимального правдоподобия (Maximum Likelihood Estimation, MLE).
  • Мы максимизируем правдоподобие наблюдения заданных меток.
$L(\beta) = \prod_{i=1}^{n} p_i^{y_i}(1-p_i)^{1-y_i}$

На практике минимизируют отрицательное логарифмическое правдоподобие (log loss) с помощью градиентного спуска или других алгоритмов оптимизации.

6. Пример расчёта

Модель даёт $\beta_0=-3$, $\beta_1=1.2$ для человека с X = 4. Найдите вероятность класса 1.

$z = -3 + 1.2 \times 4 = 1.8$

$P(Y{=}1) = \dfrac{1}{1+e^{-1.8}} \approx 0.858$

При пороге 0.5: $P(Y{=}1) = 0.858 \ge 0.5$ → прогнозируем класс 1

7. Метрики оценки

Accuracy
(Точность)		$\dfrac{TP+TN}{TP+TN+FP+FN}$
Precision
(Точность прогноза)		$\dfrac{TP}{TP+FP}$
Recall (Sensitivity)
(Полнота)		$\dfrac{TP}{TP+FN}$
F1-Score$\dfrac{2\times(\text{Prec}\times\text{Rec})}{\text{Prec}+\text{Rec}}$
ROC-AUCПлощадь под ROC-кривой (общая оценка качества)

  • TN: правильный прогноз 0
  • TP: правильный прогноз 1
  • FP: прогноз 1, а факт 0
  • FN: прогноз 0, а факт 1

9. Применение в реальном мире

Обнаружение спама (спам / не спам)
Диагностика заболеваний (болезнь / нет болезни)
Обнаружение мошенничества (мошенничество / легитимно)
Прогноз оттока клиентов (уйдёт / останется)
Одобрение кредита (одобрить / отклонить)

10. Ключевые выводы

Логистическая регрессия используется для бинарной классификации.
Классификация выполняется с использованием порога (обычно 0.5).
Использует сигмоидную функцию для предсказания вероятности (0–1).
Оценка через accuracy, precision, recall, F1-score и ROC-AUC.
Параметры находятся методом максимального правдоподобия.
Широко применяется в обнаружении спама, здравоохранении, финансах, прогнозе оттока клиентов.
