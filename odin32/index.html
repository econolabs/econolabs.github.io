Лекция: Регистрация и знакомство с GigaChat

1.1. Что такое GigaChat и его возможности

GigaChat — это мультимодальная нейросеть от Сбера, которая объединяет в себе возможности чат-бота с генерацией текста, изображений и анализа данных. Это одна из ведущих российских AI-платформ, доступная для бизнеса и частных пользователей.

Ключевые возможности GigaChat:

  • Генерация текста: написание статей, писем, постов, сценариев, ответов на вопросы.
  • Генерация изображений: создание картинок по текстовому описанию (на базе Kandinsky).
  • Анализ файлов: загрузка и анализ документов (PDF, Word, Excel), извлечение данных, реферирование.
  • Работа с кодом: написание, объяснение и отладка программного кода на разных языках.
  • Голосовой ввод и вывод: взаимодействие через голосовые сообщения.
  • Поиск в интернете: доступ к актуальной информации (в некоторых режимах).

Где используется: веб-версия (giga.chat), мобильное приложение (iOS/Android), Telegram-бот, а также API для интеграции в бизнес-приложения.

Ключевая идея: GigaChat — это универсальный AI-помощник, способный решать широкий спектр задач от творческих до аналитических.

1.2. Пошаговая регистрация в GigaChat

Регистрация в GigaChat проста и занимает всего несколько минут. Для доступа к сервису не обязательно быть клиентом Сбера — достаточно иметь номер телефона.

Способы регистрации:

Способ доступаДействия
Веб-версия 1. Перейдите на сайт giga.chat
2. Нажмите "Войти" → выберите "Зарегистрироваться"
3. Введите номер телефона → получите SMS-код
4. Введите код → укажите имя → готово!
Мобильное приложение 1. Скачайте приложение GigaChat в App Store или Google Play
2. Откройте приложение → нажмите "Зарегистрироваться"
3. Введите номер телефона → подтвердите по SMS
4. Укажите имя и настройте профиль
Telegram-бот 1. Найдите бота @GigaChatBot в Telegram
2. Нажмите "Старт" → следуйте инструкциям для привязки номера телефона
3. Подтвердите вход через веб-версию или приложение
🌟 Важно: для работы с GigaChat требуется подтверждение номера телефона. Это необходимо для контроля лимитов и безопасности.

1.3. Интерфейс GigaChat и тарифные планы

Интерфейс GigaChat интуитивно понятен и организован как диалоговое окно. После входа вы попадаете в чат, где можно начать общение с AI.

Основные элементы интерфейса:

  • Панель слева: список диалогов (чатов), кнопка создания нового чата, доступ к настройкам.
  • Центральная область: окно диалога с историей сообщений.
  • Панель ввода: поле для текста, кнопки для загрузки файлов, голосового ввода, выбора режима работы.
  • Верхняя панель: название текущего чата, информация о тарифном плане, настройки профиля.

Тарифные планы GigaChat (2026):

  • Бесплатный (Basic): базовый доступ к чату, ограниченное количество генераций изображений (до 10 в сутки), текст до 2000 символов.
  • Платная подписка (Plus или Pro): увеличенные лимиты генерации, приоритетный доступ, расширенные модели, коммерческое использование.
  • Для бизнеса (Enterprise): интеграция через API, выделенные мощности, кастомные модели, поддержка SLA.

Совет: начните с бесплатного тарифа — его достаточно для знакомства и выполнения большинства учебных задач.

Практика: Работа с GigaChat

2.1. Практика: ваш первый запрос к GigaChat

Задача: после регистрации на giga.chat, отправьте несколько запросов, чтобы познакомиться с возможностями нейросети.

Примеры запросов для тестирования:

  • Текст: "Напиши короткое приветственное письмо для новых клиентов интернет-магазина."
  • Изображение: "Нарисуй логотип для кофейни в стиле минимализм, с чашкой кофе."
  • Анализ: "Объясни, что такое инфляция, простыми словами."
  • Код: "Напиши функцию на Python для расчета факториала."
  • Креатив: "Придумай слоган для бренда спортивной одежды."

План действий:

  1. Войдите в GigaChat через веб-версию или приложение.
  2. Введите один из предложенных запросов в поле ввода.
  3. Нажмите "Отправить" (или Enter) и дождитесь ответа.
  4. Попробуйте разные запросы, чтобы оценить разнообразие возможностей.
  5. Попросите GigaChat "расскажи о себе" или "что ты умеешь".

Результат: вы получите первый опыт взаимодействия с мультимодальной нейросетью и увидите, как быстро она обрабатывает разные типы запросов.

Совет: не бойтесь экспериментировать! Чем более детально вы сформулируете запрос, тем лучше будет результат.

2.2. Практика: анализ документов и файлов в GigaChat

Задача: научиться загружать и анализировать различные файлы в GigaChat, используя его мультимодальные возможности.

Поддерживаемые форматы файлов:

  • Документы: PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), текстовые файлы (.txt).
  • Изображения: JPG, PNG, GIF (для распознавания, анализа, генерации вариаций).

Пошаговая инструкция:

  1. В окне чата найдите кнопку "Загрузить файл" (скрепка или значок "+").
  2. Загрузите любой текстовый документ (например, небольшой PDF-файл или скриншот).
  3. Напишите в чате запрос: "Проанализируй этот документ и выдели главное" или "Извлеки все даты и суммы из этого файла".
  4. Для изображения: загрузите картинку и спросите: "Что изображено на этой картинке?" или "Опиши этот объект".
  5. Оцените качество анализа и извлечения данных.
⚡ Результат: вы научитесь использовать GigaChat для работы с файлами, что особенно полезно для анализа договоров, отчетов, сканов документов и других бизнес-материалов.

2.3. Практика: генерация и редактирование изображений

Задача: освоить создание изображений по текстовому описанию в GigaChat, используя встроенную модель Kandinsky.

Как генерировать изображения:

  1. В поле ввода напишите запрос, начинающийся с ключевого слова: "Нарисуй", "Создай изображение" или просто подробно опишите, что хотите получить.
  2. Добавьте детали: стиль, цветовую гамму, настроение, композицию.
  3. Отправьте запрос и дождитесь генерации.
  4. При необходимости попросите "Измени стиль на акварель" или "Сделай фон темнее".

Примеры промптов для изображений:

  • Пейзаж: "Нарисуй горный пейзаж с озером, закат, в стиле импрессионизма."
  • Портрет: "Создай портрет девушки с книгой в старинной библиотеке, масляная живопись."
  • Киберпанк: "Изобрази футуристический город в стиле киберпанк, с неоновыми огнями, 4K."
  • Логотип: "Нарисуй логотип для IT-компании в виде стилизованной буквы 'A', минимализм."

Результат: вы научитесь создавать уникальные изображения для презентаций, соцсетей, дизайна и других целей, используя только текстовое описание.

Совет: попробуйте использовать конструктор стилей в GigaChat — он позволяет выбрать готовый стиль (аниме, 3D-рендер, хохлома, Айвазовский и др.) для более точного результата.

Самостоятельная работа: Изучение и эксперименты

3.1. Самостоятельное изучение интерфейса GigaChat

Цель работы: самостоятельно исследовать все функции и настройки интерфейса GigaChat, чтобы эффективно использовать их в своей работе.

Задания для изучения:

  • Создание и управление чатами: создайте новый чат, переименуйте его, удалите лишние. Поймите, как организована история диалогов.
  • Настройки профиля: зайдите в настройки аккаунта. Изучите разделы: "Безопасность", "Тарифы", "История", "Язык".
  • Работа с конструктором промптов: найдите раздел с готовыми шаблонами запросов (если есть). Оцените, как они помогают в работе.
  • Голосовой ввод: попробуйте использовать микрофон для отправки голосового сообщения. Оцените качество распознавания.
  • Настройка внешнего вида: проверьте, есть ли возможность изменить тему (светлая/темная), размер шрифта.

Результат: вы будете уверенно ориентироваться в интерфейсе GigaChat и сможете быстро настраивать его под свои задачи.

3.2. Эксперименты с различными типами промптов

Цель работы: провести серию экспериментов с промптами (запросами) в GigaChat, чтобы понять, как формулировка влияет на качество ответа.

Задания для экспериментов:

Тип промптаПример (плохо)Пример (хорошо)
Текст "Напиши про смартфоны" "Напиши статью о новых смартфонах 2026 года, сравни их характеристики и цену, сделай акцент на камерах."
Изображение "Нарисуй кота" "Нарисуй рыжего кота, сидящего на подоконнике, за окном идет дождь, в стиле акварели."
Код "Напиши код на Python" "Напиши функцию на Python, которая принимает список чисел и возвращает отсортированный список по возрастанию, с комментариями."

Анализ результатов:

  1. Отправьте "плохой" запрос, затем "хороший" запрос на одну тему.
  2. Сравните ответы — оцените разницу в качестве, детализации, полезности.
  3. Сделайте вывод: какие элементы делают промпт эффективным.
  4. Сохраните 3-5 удачных шаблонов для будущего использования.

Результат: вы приобретете навыки эффективного промпт-инжиниринга, которые позволят получать максимально полезные результаты от GigaChat.

3.3. Создание личных шаблонов промптов для частых задач

Цель работы: разработать и сохранить набор персонализированных шаблонов промптов для задач, которые вы решаете чаще всего (учеба, работа, творчество).

Этапы создания шаблона:

  1. Определите задачу: Например, "Создание поста для LinkedIn", "Написание письма клиенту", "Генерация идеи для проекта".
  2. Сформулируйте структуру: Опишите, что должен включать шаблон (контекст, роль AI, конкретные пункты).
  3. Создайте шаблон: Используйте переменные (в фигурных скобках) для подстановки конкретных данных.
  4. Протестируйте: Примените шаблон на практике, подставив свои данные.
  5. Откорректируйте: Улучшите шаблон на основе полученных результатов.

Пример шаблона для поста в соцсети:

"Ты — профессиональный копирайтер. Напиши пост для LinkedIn на тему {тема}. Пост должен быть:
- с цепляющим заголовком,
- содержать 3 ключевые мысли,
- заканчиваться призывом к действию,
- использовать {тон} (например, вдохновляющий, деловой, юмористический)."

Результат: вы создадите свою библиотеку промптов, которая позволит быстро и качественно решать повторяющиеся задачи в GigaChat.

Резюме: GigaChat — мощный и доступный инструмент. Ключ к эффективной работе с ним — понимание его возможностей, умение формулировать запросы и навык создания персонализированных шаблонов.
