2. Типы данных и шкалы измерений

1. Типы данных (по природе)

Качественные (категориальные)
  • Описывают качества или категории.
  • Нечисловые данные.
  • Делятся на номинальные и порядковые.
  • Примеры: пол, цвет, группа крови, уровень удовлетворённости.
Количественные (числовые)
  • Представляют числовые значения.
  • Могут быть измерены или подсчитаны.
  • Делятся на дискретные и непрерывные.
  • Примеры: возраст, рост, вес, число студентов, температура.

2. Типы данных (по значениям)

Дискретные данные
  • Принимают только конкретные, счётные значения.
  • Обычно целые числа.
  • Получаются путём подсчёта.
  • Примеры: число студентов, число машин, число звонков.
Непрерывные данные
  • Могут принимать любое значение в диапазоне.
  • Получаются путём измерения.
  • Могут быть дробными значениями.
  • Примеры: рост, вес, время, температура, зарплата.

6. Примеры из реального мира

  • Электронная коммерция: данные клиентов (структурированные), отзывы о товарах (неструктурированные), логи кликов (полуструктурированные).
  • Здравоохранение: медицинские карты (структурированные), записи врачей (неструктурированные), данные сенсоров (полуструктурированные).
  • Социальные сети: профили пользователей (структурированные), посты (неструктурированные), логи активности (полуструктурированные).
  • Финансы: данные транзакций (структурированные), письма в поддержку (неструктурированные), логи API (полуструктурированные).

7. Ключевые моменты для запоминания

  • Выбирайте правильную шкалу измерения в зависимости от типа данных.
  • Категориальные данные — качественные, числовые — количественные.
  • Дискретные данные — счётные, непрерывные — измеримые.
  • Шкала измерения определяет, какие статистические методы можно использовать.
  • Реальные данные могут быть структурированными, полуструктурированными или неструктурированными.
