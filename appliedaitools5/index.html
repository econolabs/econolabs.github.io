1. Yandex DataSphere

Полный аналог Google Colab на базе JupyterLab. Работает без VPN, принимает карты РФ, дает стартовые гранты при регистрации.

Инструкция по регистрации:
  1. Войдите в свой Яндекс ID и перейдите в консоль Yandex Cloud.
  2. Создайте платежный аккаунт (потребуется привязать карту РФ — спишется и вернется 1 рубль).
  3. Активируйте приветственный грант для новых пользователей в панели управления.
  4. В меню слева выберите раздел DataSphere, создайте проект и запустите Jupyter-ноутбук.
2. Сбер GigaChat API

Интеграция готовой текстовой модели через Python. Идеально, чтобы за 5 строк кода научить студентов создавать чат-ботов.

Как получить токен доступа:
  1. Перейдите на портал для разработчиков Сбер_Business / Studio.
  2. Войдите по Сбер ID (подходит обычный личный аккаунт) и примите условия оферты.
  3. Создайте новый проект в разделе GigaChat API (для личного использования тариф бесплатный).
  4. Скопируйте сгенерированный Client Secret или токен авторизации для вставки в Python-код.
Не требуют VPN и стабильно работают из РФ

11. Простой RAG

Базовый пример Retrieval-Augmented Generation

!pip install -q langchain langchain-community langchain-huggingface faiss-cpu

from langchain.text_splitter import CharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain.vectorstores import FAISS
from langchain.chains import RetrievalQA
from langchain_huggingface import HuggingFacePipeline

# Тестовые документы
documents = [
    "Искусственный интеллект — это область компьютерных наук, которая занимается созданием машин, способных выполнять задачи, требующие человеческого интеллекта.",
    "Google Colab — бесплатная облачная среда для работы с Jupyter Notebook, которая предоставляет GPU.",
    "RAG (Retrieval-Augmented Generation) — техника, при которой модель сначала ищет релевантную информацию, а потом генерирует ответ."
]

text_splitter = CharacterTextSplitter(chunk_size=300, chunk_overlap=50)
docs = text_splitter.create_documents(documents)

embeddings = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(docs, embeddings)

llm = HuggingFacePipeline.from_model_id(
    model_id="gpt2",
    task="text-generation",
    pipeline_kwargs={"max_new_tokens": 150, "temperature": 0.7}
)

qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=vectorstore.as_retriever(search_kwargs={"k": 2})
)

query = "Что такое RAG?"
print(qa_chain.run(query))
12. RAG с загрузкой PDF

Загружаем PDF → извлекаем текст → отвечаем по документу

!pip install -q langchain langchain-community langchain-huggingface pypdf faiss-cpu

from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain.vectorstores import FAISS
from langchain.chains import RetrievalQA
from langchain_huggingface import HuggingFacePipeline
from google.colab import files

# 1. Загрузка PDF
print("Загрузите ваш PDF-файл:")
uploaded = files.upload()
pdf_file = list(uploaded.keys())[0]

loader = PyPDFLoader(pdf_file)
documents = loader.load()
print(f"Загружено {len(documents)} страниц")

# 2. Разбиваем на чанки
text_splitter = RecursiveCharacterTextSplitter(chunk_size=800, chunk_overlap=100)
texts = text_splitter.split_documents(documents)

# 3. Векторная база
embeddings = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(texts, embeddings)

# 4. LLM
llm = HuggingFacePipeline.from_model_id(
    model_id="gpt2",
    task="text-generation",
    pipeline_kwargs={"max_new_tokens": 200, "temperature": 0.7}
)

# 5. RAG
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=vectorstore.as_retriever(search_kwargs={"k": 3}),
    return_source_documents=True
)

query = "Кратко расскажи, о чём этот документ?"
result = qa_chain(query)
print("Ответ:", result['result'])

from langchain.document_loaders import TextLoader
from langchain.text_splitter import CharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain.vectorstores import FAISS
from langchain.chains import RetrievalQA
from langchain.llms import HuggingFacePipeline
from transformers import pipeline

# 1. Создаём тестовые документы
documents = [
    "Искусственный интеллект — это область компьютерных наук, которая занимается созданием машин, способных выполнять задачи, требующие человеческого интеллекта.",

]

text_splitter = CharacterTextSplitter(chunk_size=300, chunk_overlap=50)

Практика ИИ: Запуск на домашнем компьютере

Пошаговое руководство по настройке окружения формата «Copy-Paste-Run» без использования облака

Шаг 1: Python

Для работы понадобится установленный язык программирования Python (версии 3.9–3.12).

Объем загрузки: ~25 МБ
Важно: при установке на Windows обязательно отметьте галочку "Add Python to PATH".
Шаг 2: Библиотеки

Откройте терминал (Командную строку / PowerShell) и выполните команду оптимизированной установки библиотек:

pip install torch torchvision --index-url https://pytorch.org requests Pillow
Объем загрузки:
• torch + torchvision (CPU): ~180 МБ
• requests + Pillow: ~5 МБ
Итого: ~185 МБ
Флаг --index-url ... /cpu отсекает тяжелые компоненты CUDA, экономя до 2.5 ГБ трафика.
Шаг 3: Старт ИИ

Создайте на компьютере файл ai_test.py, вставьте в него учебный код на PyTorch и запустите через терминал:

python ai_test.py
Динамическая загрузка при первом старте:
• Вес модели MobileNet_V3: ~9.8 МБ (скачивается автоматически один раз)
• Тестовое изображение: ~100 КБ
Email может быть фиктивный. Пароль НЕ требуется
Выберите тестовое задание
