8. Случайные величины (Random Variables)

1. Что такое случайная величина?

  • Случайная величина (random variable) — это числовое значение, представляющее исход случайного эксперимента.
  • Она ставит в соответствие каждому исходу из пространства элементарных исходов некоторое число.
  • Случайные величины могут быть дискретными или непрерывными.
  • Используются для анализа и обобщения случайных явлений в реальных задачах.

2. Виды случайных величин

Дискретная случайная величина
(Discrete Random Variable)
  • Принимает счётные значения (например, 0, 1, 2, ...).
  • Используется, когда исходы подсчитываются.
Примеры:
  • Число орлов при 3 подбрасываниях монеты
  • Число отсутствующих студентов в классе
Непрерывная случайная величина
(Continuous Random Variable)
  • Принимает любое значение в диапазоне (например, действительные числа).
  • Используется, когда исходы измеряются.
Примеры:
  • Рост человека
  • Время выполнения задачи
  • Температура

3. Распределение вероятностей

  • Распределение вероятностей (probability distribution) показывает вероятность каждого возможного значения случайной величины.
  • Для дискретных случайных величин используется функция вероятности (PMF).
  • Для непрерывных случайных величин используется плотность вероятности (PDF).

4. Функция вероятности (PMF)

Для дискретной случайной величины X:

$P(X=x) = $ вероятность того, что X примет значение $x$
  • $0 \le P(X=x) \le 1$
  • $\sum P(X=x) = 1$

Пример: Бросок честной кости (X = число на кости)

x123456
P(X=x)1/61/61/61/61/61/6

5. Плотность вероятности (PDF)

Для непрерывной случайной величины X:

$f(x) \ge 0$ и $\int_{-\infty}^{\infty} f(x)\,dx = 1$
  • $P(a \le X \le b) = \int_a^b f(x)\,dx$
  • $P(X=x)=0$ (для любого отдельного значения)

Пример: Равномерное распределение (от 0 до 1)

$f(x)=1$ ($0 \le x \le 1$), $f(x)=0$ (в остальных случаях)

6. Функция распределения (CDF)

Функция распределения (CDF) даёт вероятность того, что случайная величина не превышает заданное значение.

$F(x) = P(X \le x)$
  • $0 \le F(x) \le 1$
  • $F(x)$ — неубывающая функция.
  • $\lim_{x \to -\infty} F(x) = 0$ и $\lim_{x \to \infty} F(x) = 1$

7. Пример — CDF для дискретной величины

Пусть X = число на честной кости.

x123456
P(X=x)1/61/61/61/61/61/6
F(x)=P(X≤x)1/62/63/64/65/66/6 (=1)

8. Пример — CDF для непрерывной величины

Пусть X ~ Uniform(0, 1).

$F(x) = \begin{cases} 0 & x<0 \\ x & 0 \le x \le 1 \\ 1 & x>1 \end{cases}$

9. Математическое ожидание и дисперсия случайной величины

Дискретная случайная величина

Математическое ожидание (Mean, Expected Value):

$E(X) = \sum x \cdot P(X=x)$

Дисперсия (Variance):

$\text{Var}(X) = \sum (x-\mu)^2 \cdot P(X=x)$
($\mu = E(X)$)
Непрерывная случайная величина

Математическое ожидание (Mean, Expected Value):

$E(X) = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$

Дисперсия (Variance):

$\text{Var}(X) = \int_{-\infty}^{\infty} (x-\mu)^2 \cdot f(x)\,dx$
($\mu = E(X)$)

10. Ключевые выводы

Случайная величина ставит в соответствие каждому исходу числовое значение.
Может быть дискретной (счётной) или непрерывной (измеримой).
PMF используется для дискретных случайных величин.
PDF используется для непрерывных случайных величин.
CDF даёт вероятность значений до x включительно.
Математическое ожидание и дисперсия описывают центр и разброс распределения.
Случайные величины широко применяются в реальных задачах: игры, контроль качества, финансы и анализ данных.
