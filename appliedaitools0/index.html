1. Google Colab: облачная среда для разработки

Бесплатная платформа для машинного обучения и анализа данных прямо в браузере

📌 Что это?
Google Colab (Colaboratory) — это бесплатный облачный сервис на базе Jupyter Notebook, который не требует установки и настройки.

🚀 Основные возможности:
• Бесплатный доступ к GPU и TPU — ускоряет обучение нейросетей
• Интеграция с Google Диском — автоматическое сохранение и совместная работа
• Встроенный AI-ассистент — помогает писать, отлаживать и объяснять код (на базе Gemini)
• Поддержка Python и популярных библиотек — TensorFlow, PyTorch, Transformers и другие

⚠️ Ограничения бесплатного тарифа:
• Оперативная память: около 12 ГБ
• Суточная квота: примерно 6 часов использования GPU
• Сессия: автоматически завершается после 30 минут бездействия
• Древние версии библиотек: некоторые пакеты прибиты гвоздями к среде

💡 Кому подходит:
✅ Студентам и начинающим — не нужна настройка
✅ Исследователям — быстрые эксперименты на GPU
✅ Преподавателям — готовые шаблоны для обучения

3. Русскоязычные модели в Google Colab: виды и требования

Какие модели работают и сколько ресурсов им нужно

🔹 Семейство ruGPT (от SberDevices)
• ruGPT3Small (~125M параметров) — базовый уровень, работает на любом GPU
• ruGPT3Medium (~1.3B) — хороший баланс качества и скорости
• ruGPT3Large (~1.3B) — более качественная версия
• ruGPT3XL (~3.8B) — самая мощная, требует много памяти
• ruGPT2Large — предшественник, 1024 токена контекста
📌 Требования: достаточно 12–16 ГБ VRAM для Small/Medium, для Large/XL нужна квантизация

🔹 Семейство Saiga (от Ilya Gusev)
• Saiga2 7B/13B — на базе LLaMA-2, дообучена на русских инструкциях
• Saiga Mistral 7B — на базе Mistral, отличное качество
• Saiga LLaMA3 8B — самая новая и мощная
⚠️ Важно: Saiga2 не рекомендуется использовать на V100 в Colab — качество ухудшается
📌 Требования: для 7B/8B нужна 4-битная квантизация, 13B — только на A100/H100

🔹 Семейство ruT5 (от SberDevices и Ilya Gusev)
• ruT5-base — для суммаризации и задач с текстом
• rut5_base_sum_gazeta — специально для реферирования новостей
📌 Требования: очень скромные, 4–8 ГБ VRAM достаточно

🔹 Другие модели
• FRED-T5 1.7B — от SberDevices, для генерации
• Vikhr-7B-Instruct — русскоязычная инструкционная модель

⚡ Общие рекомендации для Colab:
• T4 GPU (16 ГБ VRAM): подходят ruGPT3Small/Medium, ruT5, а также 7B модели с 4-бит квантизацией
• A100 (40+ ГБ): можно запускать ruGPT3Large/XL и 13B модели без квантизации
• Всегда проверяйте: torch.cuda.is_available() и используйте device_map="auto"

11. Простой RAG (Retrieval-Augmented Generation)

Загружаем документы и отвечаем на вопросы с использованием знаний из них

!pip install -q langchain langchain-text-splitters langchain-huggingface langchain-community faiss-cpu transformers torch accelerate sentence-transformers

from langchain_text_splitters import CharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from transformers import pipeline
import torch

# 1. Создаём тестовые документы
documents = [
    "Искусственный интеллект — это область компьютерных наук, которая занимается созданием машин, способных выполнять задачи, требующие человеческого интеллекта.",
    "Google Colab — бесплатная облачная среда для работы с Jupyter Notebook, которая предоставляет GPU и TPU.",
    "RAG (Retrieval-Augmented Generation) — это техника, при которой модель сначала ищет релевантную информацию, а потом генерирует ответ. RAG помогает улучшить качество ответов LLM.",
    "Для работы с RAG необходимо создать векторную базу данных, которая хранит эмбеддинги документов."
]

# 2. Разбиваем текст на чанки
text_splitter = CharacterTextSplitter(
    chunk_size=300,
    chunk_overlap=50,
    separator="."
)
docs = text_splitter.create_documents(documents)
print(f"Created {len(docs)} document chunks")

# 3. Создаём эмбеддинги и векторную базу
print("Creating embeddings...")
embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2",
    model_kwargs={'device': 'cuda' if torch.cuda.is_available() else 'cpu'}
)
vectorstore = FAISS.from_documents(docs, embeddings)
print("✅ Vector store created!")

# 4. Создаём retriever
retriever = vectorstore.as_retriever(
    search_kwargs={"k": 2}
)

# 5. Создаём LLM
print("Loading model...")
generator = pipeline(
    "text-generation",
    model="google/flan-t5-small",
    max_new_tokens=200,
    temperature=0.7,
    device=0 if torch.cuda.is_available() else -1
)
print("✅ Model loaded!")

# 6. RAG функция
def simple_rag(query):
    print(f"\n🔍 Searching for: '{query}'")
    retrieved_docs = retriever.invoke(query)
    print(f"📄 Found {len(retrieved_docs)} relevant documents:")
    for i, doc in enumerate(retrieved_docs, 1):
        print(f" {i}. {doc.page_content[:100]}...")
    context = "\n".join([doc.page_content for doc in retrieved_docs])
    prompt = f"""Context: {context}

Question: {query}

Answer:"""
    result = generator(prompt, max_new_tokens=200)[0]['generated_text']
    if result.startswith(prompt):
        answer = result[len(prompt):].strip()
    else:
        answer = result
    return answer, retrieved_docs

# 7. Задаём вопросы
print("\n" + "="*60)
print("RAG SYSTEM TEST")
print("="*60)

test_queries = [
    "Что такое RAG?",
    "Что такое искусственный интеллект?",
    "Что такое Google Colab?"
]

for query in test_queries:
    answer, sources = simple_rag(query)
    print("\n" + "="*60)
    print(f"❓ QUESTION: {query}")
    print("="*60)
    print(f"💡 ANSWER: {answer}")
    print("="*60)
    print("📚 SOURCES:")
    for i, doc in enumerate(sources, 1):
        print(f" {i}. {doc.page_content}")
    print("="*60)

12. RAG с загрузкой документа из интернета

Загружаем большой русскоязычный документ из интернета и отвечаем на вопросы по его содержанию

!pip install -q langchain langchain-text-splitters langchain-huggingface langchain-community faiss-cpu transformers torch accelerate sentence-transformers requests beautifulsoup4

from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_community.document_loaders import WebBaseLoader
from transformers import pipeline
import torch
import requests
from bs4 import BeautifulSoup

# 1. Загружаем русскоязычный документ из интернета
# Например, статью с Википедии о искусственном интеллекте
url = "https://ru.wikipedia.org/wiki/Искусственный_интеллект"
print(f"📥 Загружаем документ: {url}")

# Загрузка с помощью requests и BeautifulSoup
response = requests.get(url, headers={'User-Agent': 'Mozilla/5.0'})
soup = BeautifulSoup(response.content, 'html.parser')

# Извлекаем текст из параграфов
paragraphs = soup.find_all('p')
text = ' '.join([p.get_text() for p in paragraphs])
# Очищаем от лишних пробелов
text = ' '.join(text.split())

print(f"📄 Загружено символов: {len(text)}")
print(f"📄 Первые 500 символов:\n{text[:500]}...")

# 2. Создаём документ для LangChain
from langchain_core.documents import Document
document = Document(page_content=text, metadata={"source": url})

# 3. Разбиваем текст на чанки (используем RecursiveCharacterTextSplitter)
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=100,
    separators=["\n\n", "\n", ".", " "],
    length_function=len
)
docs = text_splitter.split_documents([document])
print(f"✂️ Создано {len(docs)} чанков")

# 4. Создаём эмбеддинги и векторную базу
print("🔨 Создаём эмбеддинги...")
embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2",
    model_kwargs={'device': 'cuda' if torch.cuda.is_available() else 'cpu'}
)
vectorstore = FAISS.from_documents(docs, embeddings)
print("✅ Векторная база создана!")

# 5. Создаём retriever
retriever = vectorstore.as_retriever(
    search_kwargs={"k": 3} # Возвращаем топ-3 релевантных чанка
)

# 6. Создаём LLM для генерации ответов
print("🤖 Загружаем модель...")
generator = pipeline(
    "text-generation",
    model="google/flan-t5-large", # Используем большую модель для лучших ответов
    max_new_tokens=250,
    temperature=0.3, # Низкая температура для более точных ответов
    device=0 if torch.cuda.is_available() else -1
)
print("✅ Модель загружена!")

# 7. RAG функция
def ask_question(query):
    print(f"\n🔍 Вопрос: '{query}'")
    
    # Поиск релевантных документов
    retrieved_docs = retriever.invoke(query)
    print(f"📄 Найдено {len(retrieved_docs)} релевантных чанков")
    for i, doc in enumerate(retrieved_docs, 1):
        print(f" {i}. {doc.page_content[:150]}...")
    
    # Формируем контекст
    context = "\n\n".join([doc.page_content for doc in retrieved_docs])
    
    # Создаём промпт
    prompt = f"""Ответь на вопрос на русском языке, используя только информацию из контекста.

Контекст:
{context}

Вопрос: {query}

Ответ:"""
    
    # Генерация ответа
    result = generator(prompt, max_new_tokens=250)[0]['generated_text']
    
    # Очистка ответа
    if result.startswith(prompt):
        answer = result[len(prompt):].strip()
    else:
        answer = result
    
    return answer, retrieved_docs

# 8. Задаём вопросы по документу
print("\n" + "="*70)
print("📖 RAG СИСТЕМА - ВОПРОСЫ ПО СТАТЬЕ")
print("="*70)

questions = [
    "Что такое искусственный интеллект?",
    "Какие основные направления включает в себя искусственный интеллект?",
    "Что такое машинное обучение и как оно связано с ИИ?",
    "Какие применения искусственного интеллекта существуют?",
    "В чем разница между слабым и сильным искусственным интеллектом?"
]

for i, query in enumerate(questions, 1):
    answer, sources = ask_question(query)
    
    print("\n" + "="*70)

from transformers import AutoTokenizer, AutoModelForSeq2SeqLM
import torch

# 1. Загружаем модель M2M-100
print("🤖 Загружаем M2M-100...")
model_name = "facebook/m2m100_418M"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
print("✅ Модель загружена!")

# 2. Функция перевода с явным указанием языка
def translate_m2m(text, src_lang, tgt_lang):
    # Устанавливаем исходный язык
    tokenizer.src_lang = src_lang
    inputs = tokenizer(text, return_tensors="pt", truncation=True, max_length=512)
    
    # Генерируем с указанием целевого языка
    with torch.no_grad():
        outputs = model.generate(
            **inputs,
            forced_bos_token_id=tokenizer.lang_code_to_id[tgt_lang],
            max_new_tokens=100,
            num_beams=4
        )
    
    return tokenizer.decode(outputs[0], skip_special_tokens=True)

# 3. Тестируем перевод
text = "Google Colab is a free cloud-based platform for machine learning."
result = translate_m2m(text, "en", "ru")
print(f"\n📝 Английский: {text}")
print(f"🇷🇺 Русский: {result}")

# Проверяем обратный перевод
