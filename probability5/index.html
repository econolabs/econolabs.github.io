5. Основы теории вероятностей (Probability Basics)

1. Что такое вероятность (Probability)?

  • Вероятность измеряет шанс наступления события.
  • Принимает значения от 0 до 1 (или от 0% до 100%).
  • 0 → Невозможное событие (Impossible event)
  • 1 → Достоверное событие (Certain event)
  • Используется для анализа неопределённости в реальных ситуациях.

2. Ключевые термины (Key Terms)

ТерминЗначение
Эксперимент
(Experiment)		Процесс, дающий чётко определённые исходы (например, бросок игральной кости).
Исход
(Outcome)		Возможный результат эксперимента (например, 1, 2, 3, 4, 5, 6).
Пространство элементарных исходов (S)
(Sample Space)		Множество всех возможных исходов (например, S = {1, 2, 3, 4, 5, 6} для кости).
Событие (A)
(Event)		Набор исходов (например, A = {2, 4, 6} для чётного числа).

3. Основная формула вероятности

$P(A) = \dfrac{\text{Число благоприятных исходов}}{\text{Общее число исходов}}$

Пример: Бросается честная игральная кость. Найдите вероятность выпадения чётного числа.

  • Благоприятные исходы = {2, 4, 6} → 3
  • Всего исходов = 6

$P(\text{Чётное}) = \dfrac{3}{6} = \dfrac{1}{2} = 0.5$

4. Виды событий (Types of Events)

ВидОписание
Достоверное событие
(Sure Event)		Всегда происходит. $P(A) = 1$
Невозможное событие
(Impossible Event)		Никогда не происходит. $P(A) = 0$
Несовместные события
(Mutually Exclusive Events)		Не могут произойти одновременно. $P(A \cap B) = 0$
Противоположное событие
(Complementary Event)		Событие, которое не происходит. $P(\bar{A}) = 1 - P(A)$

5. Важные формулы

  • $0 \le P(A) \le 1$
  • $P(\bar{A}) = 1 - P(A)$
  • $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ (для любых двух событий)
  • Если $A$ и $B$ несовместны: $P(A \cup B) = P(A) + P(B)$
  • Если $A$ и $B$ независимы: $P(A \cap B) = P(A) \times P(B)$

6. Диаграммы Венна (Venn Diagrams)

Несовместные события
(Mutually Exclusive)

$A \cap B = \varnothing$
$P(A \cup B) = P(A)+P(B)$

Пересекающиеся события
(Overlapping)

$P(A \cup B){=}P(A){+}P(B){-}P(A \cap B)$

Противоположное событие
(Complementary)

$P(\bar{A}) = 1 - P(A)$

7. Примеры из реального мира

Подбрасывание монеты: $P(\text{Орёл}) = \dfrac{1}{2}$, $P(\text{Решка}) = \dfrac{1}{2}$
Бросок кости: $P(\text{выпадение } 3) = \dfrac{1}{6}$
Вытягивание карты: $P(\text{туз из 52 карт}) = \dfrac{4}{52} = \dfrac{1}{13}$
Опрос: если 30 из 100 студентов любят предмет, $P(\text{нравится}) = 30/100 = 0.3$
Погода: если дождь идёт 20 дней из 100, $P(\text{дождь}) = 0.2$

8. Примеры задач

Пример 1: Подбрасывание монеты

Подбрасывается монета. Найдите вероятность выпадения орла.

  • Благоприятные исходы = 1
  • Всего исходов = 2

$P(\text{Орёл}) = \dfrac{1}{2} = 0.5$

Пример 2: Две кости

Бросаются две кости. Найдите вероятность того, что сумма равна 7.

  • Благоприятные исходы = {(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)} → 6
  • Всего исходов = 6 × 6 = 36

$P(\text{Сумма}=7) = \dfrac{6}{36} = \dfrac{1}{6}$

9. Ключевые выводы

Значения лежат в диапазоне от 0 до 1.
Понимайте ключевые термины: эксперимент, исход, пространство элементарных исходов, событие.
Используйте правильные формулы в зависимости от вида события.
Диаграммы Венна помогают визуализировать события.
Вероятность широко применяется в реальных сценариях: игры, опросы, прогнозирование погоды.
