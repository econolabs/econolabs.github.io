# Методы стратегического анализа и планирования

## 1. Модель 5 сил М. Портера: структурный анализ отрасли

**Назначение:** Оценка привлекательности отрасли и уровня конкуренции.

> **Оценка влияния сил (пример для розничной торговли продуктами питания)**

| Сила | Степень влияния (1-5) | Почему |
|------|----------------------|--------|
| Угроза новичков | **4** | Низкие барьеры: можно открыть магазин или запустить доставку. |
| Власть поставщиков | **3** | Сети могут давить на фермеров, но бренды (Coca-Cola) сильны. |
| Власть покупателей | **5** | Покупатель легко переключается между магазинами, чувствителен к цене. |
| Угроза субститутов | **3** | Рестораны / доставка готовой еды — частичный заменитель. |
| Соперничество | **5** | Ценовые войны, акции, борьба за каждого клиента. |

**Итог:** отрасль **низкой привлекательности** для новичков, прибыльность поддерживается только за счёт сверхэффективности.

## 2. PESTEL-анализ: макросреда

**Назначение:** Анализ внешних факторов, влияющих на компанию.

> **PESTEL-анализ для финтех-стартапа**

| Категория | Факторы | Влияние | Возможности / Угрозы |
|-----------|---------|---------|---------------------|
| **P**olitical (Политика) | Регулирование криптовалют, санкции | Высокое | Угроза: запрет операций |
| **E**conomic (Экономика) | Ключевая ставка, инфляция, курс валют | Среднее | Возможность: рост спроса на защиту капитала |
| **S**ocial (Социум) | Цифровая грамотность, доверие к онлайн-банкам | Высокое | Возможность: молодёжь активно переходит в финтех |
| **T**echnological (Технологии) | ИИ, блокчейн, биометрия | Высокое | Возможность: создание инновационных продуктов |
| **E**nvironmental (Экология) | ESG-повестка, углеродный след | Низкое | Возможность: "зелёные" инвестиции |
| **L**egal (Право) | Закон о персональных данных, лицензирование | Высокое | Угроза: штрафы за нарушение 152-ФЗ |

**Итог:** Благоприятная среда для технологических инноваций, но требуется строгое соблюдение законодательства.

## 3. SWOT-анализ: комплексная оценка

**Назначение:** Выявление сильных/слабых сторон, возможностей и угроз.

> **SWOT-анализ для интернет-магазина электроники**

| | **Strengths (Сильные стороны)** | **Weaknesses (Слабые стороны)** |
|---|---|---|
| **Internal** | Широкий ассортимент, быстрая доставка, лояльность клиентов | Высокие логистические затраты, устаревший сайт, нехватка персонала |

| | **Opportunities (Возможности)** | **Threats (Угрозы)** |
|---|---|---|
| **External** | Выход на маркетплейсы, внедрение ИИ-рекомендаций, франчайзинг | Рост конкуренции, повышение пошлин, уход поставщиков |

**Стратегии:**
- **SO (Силы + Возможности):** Запуск ИИ-рекомендаций для увеличения продаж.
- **WO (Слабости + Возможности):** Автоматизация склада для снижения затрат.
- **ST (Силы + Угрозы):** Укрепление бренда для защиты от конкурентов.
- **WT (Слабости + Угрозы):** Оптимизация затрат для снижения цен.

## 4. SPACE-матрица: стратегическая позиция

**Назначение:** Определение типа стратегии на основе позиции компании.

> **SPACE-матрица для производственной компании**

| Ось | Показатель | Оценка (1-6) |
|-----|------------|-------------|
| **FS** (Финансовая сила) | Рентабельность, ликвидность, оборачиваемость | 5 |
| **CA** (Конкурентное преимущество) | Доля рынка, качество, лояльность | 4 |
| **ES** (Стабильность среды) | Темп роста рынка, барьеры входа, инфляция | 2 |
| **IS** (Привлекательность отрасли) | Рентабельность отрасли, потенциал роста | 5 |

**Результат:** Агрессивная стратегия (FS + IS высокие, ES + CA низкие) — рекомендуется рост, захват рынка.

## 5. BCG-матрица: портфельный анализ

**Назначение:** Оценка продуктов/бизнес-единиц по доле рынка и темпам роста.

> **BCG-матрица для IT-компании**

| Продукт | Доля рынка | Темп роста | Квадрант | Стратегия |
|---------|------------|------------|----------|-----------|
| Облачные решения | Высокая | Высокий | **«Звезда»** | Инвестировать в рост |
| Коробочный софт | Высокая | Низкий | **«Дойная корова»** | Поддерживать, извлекать прибыль |
| Мобильное приложение | Низкая | Высокий | **«Трудный ребёнок»** | Анализировать, либо инвестировать |
| Устаревший продукт | Низкая | Низкий | **«Собака»** | Ликвидировать или продать |

**Итог:** Фокус на «Звёздах» и монетизации «Дойных коров».

## 6. Анализ цепочки создания ценности (Value Chain)

**Назначение:** Выявление источников конкурентного преимущества.

> **Цепочка ценности для розничной сети**

| Основные виды деятельности | Вспомогательные виды деятельности |
|----------------------------|-----------------------------------|
| **Входящая логистика:** Склады, приёмка товара | **Инфраструктура:** Управление, финансы, юридический отдел |
| **Операции:** Выкладка, мерчандайзинг | **Управление персоналом:** Найм, обучение, мотивация |
| **Исходящая логистика:** Доставка, выдача | **Развитие технологий:** Сайт, мобильное приложение, CRM |
| **Маркетинг и продажи:** Реклама, акции | **Закупки:** Переговоры с поставщиками |
| **Сервис:** Возврат, постпродажное обслуживание | |

**Ключевое преимущество:** Инвестиции в IT (развитие технологий) обеспечивают превосходство над конкурентами.

## 7. Матрица Ансоффа: стратегии роста

**Назначение:** Определение направления роста компании.

> **Матрица Ансоффа для продуктовой компании**

| | **Существующие рынки** | **Новые рынки** |
|---|---|---|
| **Существующие продукты** | **Проникновение на рынок** — усиление маркетинга, акции | **Развитие рынка** — выход в регионы, экспорт |
| **Новые продукты** | **Развитие продукта** — вывод новых вкусов, улучшение рецептуры | **Диверсификация** — запуск линейки здорового питания |

**Рекомендация:** Начать с **проникновения на рынок** (наименьший риск), затем диверсифицироваться.

## 8. McKinsey 7S: внутренняя диагностика

**Назначение:** Оценка внутренней согласованности компании.

> **7S для IT-компании в период цифровой трансформации**

| Элемент | Текущее состояние | Целевое состояние |
|---------|-------------------|-------------------|
| **Стратегия (Strategy)** | Лидерство по цене | Продуктовое лидерство |
| **Структура (Structure)** | Функциональная | Матричная (по продуктам) |
| **Системы (Systems)** | Устаревший документооборот | Agile, Jira, DevOps |
| **Ключевые компетенции (Skills)** | Разработка | AI/ML, облачные технологии |
| **Стиль (Style)** | Иерархический | Гибкий, самоорганизующийся |
| **Штат (Staff)** | 500 чел. | 700 чел. (+ AI-инженеры) |
| **Ценности (Shared Values)** | Надёжность | Инновации + качество |

**Итог:** Необходимо синхронизировать изменения по всем 7 элементам для успешной трансформации.

## 9. GAP-анализ: стратегический разрыв

**Назначение:** Сравнение текущего и целевого состояния.

> **GAP-анализ для логистической компании**

| Показатель | Текущее значение | Целевое значение (через 3 года) | Разрыв (GAP) |
|------------|------------------|--------------------------------|--------------|
| Выручка, млн ₽ | 500 | 900 | 400 |
| Доля рынка, % | 8 | 15 | 7 |
| Количество клиентов | 1200 | 2500 | 1300 |
| Время доставки, часы | 48 | 24 | 24 |

**Способы закрытия GAP:**
1. Запуск экспресс-доставки в крупных городах.
2. Привлечение крупных корпоративных клиентов.
3. Открытие 5 новых складов.

## 10. Анализ конкурентов (Бенчмаркинг)

**Назначение:** Сравнение компании с лидерами рынка.

> **Сравнительный анализ доставки еды**

| Критерий | Мы | Конкурент А | Конкурент Б |
|----------|----|-------------|-------------|
| Время доставки, мин | 45 | 30 ✅ | 35 |
| Средний чек, ₽ | 800 | 950 | 700 ✅ |
| Ассортимент (блюд) | 120 | 200 ✅ | 150 |
| Рейтинг в App Store | 4.2 | 4.7 ✅ | 4.4 |
| Наличие промокодов | Редко | Постоянно ✅ | Иногда |

**Зоны роста:** Улучшить приложение (до 4.7+) и запустить систему скидок.

## 11. VRIO-анализ: устойчивое преимущество

**Назначение:** Оценка ресурсов компании по критериям VRIO.

> **VRIO-анализ для технологического стартапа**

| Ресурс | V (Ценность) | R (Редкость) | I (Сложность имитации) | O (Организация) | Результат |
|--------|--------------|--------------|------------------------|----------------|-----------|
| Алгоритмы ИИ | ✅ Да | ✅ Да | ✅ Да | ✅ Да | **Устойчивое преимущество** |
| Патенты | ✅ Да | ✅ Да | ✅ Да | ❌ Нет (некоммерциализированы) | **Неиспользуемый потенциал** |
| Команда разработчиков | ✅ Да | ❌ Нет (все нанимают) | ❌ Нет | ✅ Да | **Временное преимущество** |
| Офис в центре | ❌ Нет (дорого) | ❌ Нет | ❌ Нет | ❌ Нет | **Конкурентный нейтралитет** |

## 12. Модель Томпсона и Стрикленда (Карта стратегий)

**Назначение:** Выбор стратегии на основе конкурентной позиции и темпов роста.

> **Карта стратегий для автопроизводителя**

| | **Быстрый рост рынка** | **Медленный рост рынка** |
|---|---|---|
| **Сильная конкурентная позиция** | Вертикальная интеграция, захват доли | Диверсификация, оптимизация |
| **Слабая конкурентная позиция** | Нишевая стратегия, поворот (pivot) | Сокращение, продажа бизнеса |

**Текущая позиция:** Рынок растёт на 8% в год, компания занимает 3-е место.
**Рекомендация:** Инвестировать в электромобили и занять нишу премиальных EV.

## 13. Balanced Scorecard (BSC): стратегическая карта

**Назначение:** Декомпозиция стратегии на цели и KPI.

> **BSC для сети кофеен**

| Перспектива | Цель | KPI | Инициатива |
|-------------|------|-----|------------|
| **Финансы** | Рост выручки на 20% | Прибыль, ROI, средний чек | Повышение цен, кросс-продажи |
| **Клиенты** | Повышение NPS до 75 | NPS, число лояльных клиентов | Программа лояльности, улучшение сервиса |
| **Процессы** | Сокращение времени приготовления до 2 мин | Время, количество ошибок | Оптимизация рецептур и оборудования |
| **Обучение** | Внедрение системы обучения бариста | Квалификация, текучесть кадров | Корпоративный университет |

## 14. Сценарирование: управление неопределённостью

**Назначение:** Разработка стратегий для разных вариантов будущего.

> **Сценарии для нефтяной компании на 2030 год**

| Сценарий | Внешние условия | Стратегия компании |
|----------|----------------|-------------------|
| **«Зелёный переход»** | Ужесточение экологических норм, рост цен на углерод | Инвестиции в ВИЭ, уход из угля |
| **«Высокие цены»** | Дефицит нефти, рост цен до $150/барр. | Максимизация добычи, накопление прибыли |
| **«Технологический прорыв»** | Дешёвый водород, электромобили | Диверсификация в водород, партнёрства |

**Базовая стратегия:** Гибкость — поддерживать портфель проектов во всех трёх направлениях.

## 15. SWOT + PESTEL: расширенный анализ

**Назначение:** Связь внутренних и внешних факторов в едином анализе.

> **Сводный анализ для ритейлера**

| | **Возможности (О)** | **Угрозы (Т)** |
|---|---|---|
| **Сильные стороны (S)** | S-O: Использовать лояльность для запуска маркетплейса | S-T: Использовать масштаб для давления на поставщиков |
| **Слабые стороны (W)** | W-O: Внедрить ИИ в логистику (инвестиции) | W-T: Оптимизировать затраты из-за инфляции |

## 17. Количественные методы (финансовое моделирование)

**Назначение:** Оценка эффективности стратегии в цифрах.

> **Финансовая модель для запуска нового продукта**

| Показатель | Значение |
|------------|----------|
| Инвестиции, млн ₽ | 150 |
| Окупаемость (PP), лет | 2.5 |
| NPV (дисконт 15%), млн ₽ | 45 |
| IRR, % | 28% |
| Точка безубыточности, ед./мес | 1 200 |

**Решение:** Проект **приемлем** (IRR > ставки дисконтирования).

## 19. Модель жизненного цикла отрасли

**Назначение:** Выбор стратегии в зависимости от этапа развития отрасли.

> **Жизненный цикл рынка электромобилей**

| Этап | Характеристика | Стратегия |
|------|---------------|-----------|
| **Зарождение** | Низкие продажи, высокая цена | Инвестиции в НИОКР, пилоты |
| **Рост** | Быстрый рост, появление конкурентов | Рыночная экспансия, масштабирование |
| **Зрелость** | Стабилизация, ценовая борьба | Оптимизация затрат, дифференциация |
| **Спад** | Снижение спроса, уход игроков | Уход или переход в новый сегмент |
