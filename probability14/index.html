14. Линейная регрессия (Linear Regression)

1. Что такое линейная регрессия?

  • Линейная регрессия — это статистический метод для нахождения связи между зависимой переменной (Y) и одной или несколькими независимыми переменными (X).
  • Она предсказывает непрерывное значение на основе входных признаков.
  • Предполагает линейную зависимость между X и Y.
  • Широко применяется в реальных задачах: прогнозирование цен, прогноз продаж, анализ рисков и т.д.

2. Модель простой линейной регрессии

$Y = \beta_0 + \beta_1 X + \varepsilon$
  • $Y$: зависимая переменная (целевая)
  • $X$: независимая переменная (признак)
  • $\beta_0$: свободный член (значение Y при X = 0)
  • $\beta_1$: коэффициент наклона (изменение Y при изменении X на 1 единицу)
  • $\varepsilon$: случайная ошибка (разность между фактическим и предсказанным значением)

3. Визуальное представление

  • Каждая точка — это наблюдение.
  • Красная линия — линия наилучшего приближения, минимизирующая ошибку.
  • Вертикальное расстояние — ошибка предсказания.

4. Как найти $\beta_0$ и $\beta_1$?

$\beta_1 = \dfrac{\sum(X_i-\bar{X})(Y_i-\bar{Y})}{\sum(X_i-\bar{X})^2}$
$\beta_0 = \bar{Y} - \beta_1\bar{X}$
  • $\bar{X}$: среднее значений X
  • $\bar{Y}$: среднее значений Y
  • $\beta_1$: наклон линии
  • $\beta_0$: свободный член (пересечение с осью Y)

5. Пример расчёта

Даны данные (площадь дома vs цена):

Площадь (X)Цена (Y)
8001.2
10001.5
12001.8
14002.1

Решение (расчётное):

  • $\beta_1$ (наклон) = 0.0015
  • $\beta_0$ (свободный член) = 0.0

Уравнение регрессии: $Y = 0.0015X$

При X = 1000 предсказанная цена = 1.5

6. Прогнозирование

Если площадь дома = 1600 кв. футов, какова предсказанная цена?

По уравнению регрессии:

$Y = 0.0015 \times 1600 + 0.0$

$Y = 2.4$

Итак, предсказанная цена для дома 1600 кв. футов равна 2.4 (в тех же единицах, например, миллионах).

7. Оценка модели (метрики)

  • MSE — средняя квадратичная ошибка (Mean Squared Error)
  • RMSE — корень из средней квадратичной ошибки (Root Mean Squared Error)
  • MAE — средняя абсолютная ошибка (Mean Absolute Error)
  • R² — коэффициент детерминации (показывает, насколько хорошо модель описывает данные)
  • Чем выше R² (ближе к 1), тем лучше.

10. Ключевые выводы

Линейная регрессия предсказывает непрерывное значение с помощью линейного уравнения.
$\beta_0$ — свободный член, $\beta_1$ — наклон.
Качество модели измеряется через MSE, RMSE, MAE и R².
Широко применяется в финансах, здравоохранении, маркетинге и прогнозировании спроса.
