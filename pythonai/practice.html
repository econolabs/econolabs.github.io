Векторы и меры сходства — как сравнивать смыслы

Чтобы найти похожие документы, нужно уметь измерять расстояние между векторами. Главный инструмент — косинусное сходство.

# Косинусное сходство (cosine similarity):
cos(θ) = (A·B) / (|A| × |B|)
результат: от 0 (не похожи) до 1 (очень похожи)

# Пример:
«кот спит» и «кошка отдыхает» → сходство 0.95
«кот спит» и «я люблю пиццу» → сходство 0.12

Косинусное сходство:

  • Игнорирует длину вектора (важен только угол)
  • Стандарт для текстовых эмбеддингов
  • 1 = одинаковый смысл, 0 = никакой связи

Другие меры:

  • Евклидово расстояние: прямое расстояние между точками
  • Манхэттенское расстояние: сумма модулей разниц
  • Для текстов: косинусное — лучший выбор

Правило для единичных векторов:
• a · b = 1 → угол 0° (сонаправлены)
• a · b = 0 → угол 90° (перпендикулярны)
• a · b = -1 → угол 180° (противоположны)
• a · b = cos(θ) для любых единичных векторов

def knn(embeddings, query, k=3):
    norms = np.linalg.norm(embeddings, axis=1)
    query_norm = np.linalg.norm(query)
    cos_sim = np.dot(embeddings, query) / (norms * query_norm)
    return np.argsort(cos_sim)[-k:][::-1]

# Пример

kNN — поиск ближайших соседей на NumPy

Для небольших векторных баз (до 1000 векторов) можно реализовать полноценный поиск на чистом NumPy без FAISS: 

import numpy as np

# ----- 1. ЗАГРУЗКА ДАННЫХ -----
# Матрица эмбеддингов (N документов, d=384)
embeddings = np.random.rand(1000, 384).astype(np.float32)

# Тексты документов (для отображения результатов)
texts = [f"Документ {i}" for i in range(1000)]

# Вектор запроса (например, эмбеддинг вопроса пользователя)
query_embedding = np.random.rand(384).astype(np.float32)

# ----- 2. НОРМАЛИЗАЦИЯ (для ускорения) -----
# Нормализованные векторы имеют длину 1 → cos = dot
embeddings_norm = embeddings / np.linalg.norm(embeddings, axis=1, keepdims=True)
query_norm = query_embedding / np.linalg.norm(query_embedding)

# ----- 3. ПОИСК k БЛИЖАЙШИХ СОСЕДЕЙ -----
k = 5
# Косинусное сходство = скалярное произведение (для нормализованных)
cos_sim = np.dot(embeddings_norm, query_norm)

# Индексы top-k (с наибольшим сходством)
top_k_idx = np.argsort(cos_sim)[-k:][::-1]
top_k_scores = cos_sim[top_k_idx]

# ----- 4. ВЫВОД РЕЗУЛЬТАТОВ -----
print(f"Топ-{k} релевантных документов:")
for i, (idx, score) in enumerate(zip(top_k_idx, top_k_scores)):
    print(f"  {i+1}. {texts[idx]} (сходство: {score:.4f})")

from sklearn.metrics import precision_score, recall_score, f1_score
from sklearn.metrics import ndcg_score, average_precision_score

# Пример: 5 документов, из них релевантные 1, 3, 4
y_true = [1, 0, 1, 1, 0]   # реальная релевантность (1 - да, 0 - нет)
y_pred = [1, 1, 0, 1, 0]   # предсказание модели

# Precision (точность): сколько из найденных — релевантны
precision = precision_score(y_true, y_pred)

# Recall (полнота): сколько релевантных нашли
recall = recall_score(y_true, y_pred)

# F1-score: среднее гармоническое precision и recall
f1 = f1_score(y_true, y_pred)

print(f"Precision: {precision:.3f}")
print(f"Recall: {recall:.3f}")
print(f"F1-score: {f1:.3f}")
# Метрики для ранжирования (top-k)
def precision_at_k(relevant, retrieved, k):
    # relevant: множество релевантных индексов
    # retrieved: список индексов в порядке ранжирования
    retrieved_k = retrieved[:k]
    return len(set(relevant) & set(retrieved_k)) / k

def recall_at_k(relevant, retrieved, k):
    retrieved_k = retrieved[:k]
    return len(set(relevant) & set(retrieved_k)) / len(relevant)

# Пример
relevant_docs = {0, 2, 4}           # релевантные документы
retrieved_docs = [0, 1, 2, 3, 4]   # порядок от модели

p5 = precision_at_k(relevant_docs, retrieved_docs, 5)
r5 = recall_at_k(relevant_docs, retrieved_docs, 5)

print(f"Precision@5: {p5:.3f}")   # 3/5 = 0.6
print(f"Recall@5: {r5:.3f}")      # 3/3 = 1.0

TF-IDF — классический baseline для сравнения с эмбеддингами 
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# Коллекция документов
documents = [
    "кот спит на диване",
    "собака бегает во дворе",
    "кот и собака дружат",
    "налоговый вычет на ребенка"
]

# Превращаем текст в TF-IDF векторы
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(documents)

# Поиск по запросу
query = "кот"
query_vec = vectorizer.transform([query])

# Косинусное сходство
similarities = cosine_similarity(query_vec, tfidf_matrix).flatten()

# Топ-2 наиболее похожих
top_idx = similarities.argsort()[-2:][::-1]
for idx in top_idx:
    print(f"{similarities[idx]:.3f} - {documents[idx]}")
