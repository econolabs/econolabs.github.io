Лекция: Чат-боты и ИИ-агенты — современные инструменты

1.1. Чат-боты и ИИ-агенты: сходства и различия

Чат-бот и ИИ-агент — это два разных уровня автоматизации общения и взаимодействия с пользователями. Понимание их различий критически важно для выбора правильного инструмента под бизнес-задачу.

ХарактеристикаЧат-ботИИ-агент
Интеллект Основан на жестких сценариях (rules) или ограниченном NLP Использует LLM, способен к рассуждению и планированию
Инструменты Обычно не использует внешние инструменты Активно использует инструменты (API, базы данных, поиск)
Память Память ограничена контекстом диалога Имеет долгосрочную память и доступ к базам знаний
Гибкость Следует строгим сценариям, плохо справляется с отклонениями Адаптируется к непредвиденным запросам и меняет план действий
Примеры Бот для записи к врачу, опросник в мессенджере Виртуальный ассистент, аналитический агент, агент-разработчик

Ключевая идея: если вам нужно обрабатывать простые, повторяющиеся запросы — чат-бот будет эффективным и недорогим решением. Для сложных задач с использованием данных и принятием решений нужен ИИ-агент.

1.2. Бизнес-сценарии применения чат-ботов

Чат-боты остаются одним из самых популярных и доступных инструментов для автоматизации коммуникаций. Их основная сила — в скорости внедрения и низкой стоимости.

Самые эффективные сценарии:

  • Клиентская поддержка: ответы на частые вопросы (FAQ), сбор заявок, обработка обращений (до 80% типовых запросов).
  • Квалификация лидов: сбор контактных данных, выявление потребностей клиента и передача в отдел продаж.
  • Онбординг и обучение: пошаговое сопровождение новых сотрудников или клиентов по процессам.
  • Информирование: оповещение о статусе заказа, событиях, акциях (push-уведомления в виде диалога).
  • Сбор обратной связи: проведение опросов и получение оценок в интерактивном формате.

Ключевые платформы: для создания чат-ботов часто используются конструкторы без кода (например, в VK, Telegram, на платформах типа Chatfuel), а также стандартные API мессенджеров.

🌟 Важно: эффективность чат-бота определяется качеством его сценариев. Даже простой бот может принести пользу, если правильно спроектирована логика диалога.

1.3. От чат-ботов к ИИ-агентам: эволюция возможностей

Современные технологии размывают границы между чат-ботами и агентами. С появлением доступных LLM и платформ для их интеграции, даже небольшие компании могут создавать продвинутых агентов.

Что изменилось:

  • Появилась возможность подключения к корпоративным данным: агенты могут читать документы, базы знаний и отвечать на основе актуальной информации.
  • Агенты могут совершать действия: не просто отвечать, а оформлять заявки, изменять данные в CRM, отправлять письма.
  • Улучшилось понимание естественного языка: агенты понимают сложные и неструктурированные запросы, обрабатывают многозадачные диалоги.
  • Появилась мультимодальность: агенты могут обрабатывать не только текст, но и голос, изображения (например, распознавать дефекты на фото).

Пример платформы для эволюции: Yandex Agent Atelier позволяет начать с простого агента-чата, а затем постепенно добавлять инструменты, превращая его в полноценного автономного помощника.

Тренд: к 2026 году большинство бизнес-чат-ботов будут так или иначе использовать LLM и элементы агентности для улучшения качества обслуживания.

Практика: Создание и интеграция ботов и агентов

2.1. Создание чат-бота для VK с использованием VK API

Задача: создать простого бота для сообщества ВКонтакте, который будет приветствовать новых участников и отвечать на заданные вопросы.

Пошаговый план:

  1. Настройка сообщества: создайте или используйте существующее сообщество VK.
  2. Создание приложения: в разделе "Управление" → "Настройки" → "Работа с API" создайте приложение и получите ключ доступа (access token).
  3. Настройка Long Poll или Callback API: выберите способ получения событий от VK. Для начала проще использовать Long Poll.
  4. Написание кода бота: используя документацию VK API Bots, напишите скрипт, который обрабатывает входящие сообщения и отправляет ответы.
  5. Запуск и тестирование: запустите скрипт на сервере (или локально с использованием ngrok) и проверьте работу бота.

Результат: работоспособный бот, который автоматизирует общение в сообществе VK и может быть базой для создания более сложных агентов.

Совет: начните с бота, который повторяет текст пользователя или отвечает на команду /start — это поможет освоить базовые механизмы работы API.

2.2. Интеграция LLM в чат-бота для улучшения ответов

Задача: усилить созданного в VK бота, подключив к нему большую языковую модель (например, YandexGPT или GigaChat) для генерации более осмысленных и контекстных ответов.

Архитектура решения:

  • Обработчик VK: получает сообщение от пользователя.
  • Промпт-инжиниринг: формирует запрос к LLM, включая контекст диалога и инструкции (System Prompt).
  • Вызов API LLM: отправляет запрос к модели (например, через OpenAI-совместимый API Yandex AI Studio).
  • Отправка ответа: полученный ответ от LLM отправляется обратно пользователю в VK.

Пример простого промпта:

"Ты — дружелюбный помощник сообщества. Отвечай на вопросы пользователей кратко и по делу. Контекст диалога: {history}"
⚡ Результат: ваш бот перестает быть "тупым" и начинает поддерживать осмысленный диалог, понимать сложные вопросы и давать полезные ответы.

2.3. Создание ИИ-агента с инструментами в Yandex Agent Atelier

Задача: разработать агента, который не только отвечает на вопросы, но и умеет выполнять действия, используя внешние инструменты. Рассмотрим пример агента для проверки статуса заказа.

Компоненты агента в Agent Atelier:

  • Инструкция: "Ты — ассистент интернет-магазина. Ты можешь проверять статус заказа по его номеру. Если пользователь спрашивает о заказе, используй инструмент для получения информации."
  • Инструмент: создается через MCP-сервер или встроенными средствами. Например, инструмент "get_order_status" принимает номер заказа и возвращает статус.
  • Память: агент запоминает предыдущие запросы пользователя, чтобы поддерживать контекст.

Пример диалога с агентом:

  • Пользователь: "Где мой заказ №12345?"
  • Агент: (вызывает инструмент get_order_status с параметром "12345")
  • Агент: "Ваш заказ №12345 находится в пути и будет доставлен завтра."

Результат: полноценный ИИ-агент, способный автономно решать реальную бизнес-задачу, взаимодействуя с данными и пользователем.

Важно: ключевое отличие агента от чат-бота — это наличие инструментов, которые он использует для достижения цели.

Самостоятельная работа: Изучение и эксперименты

3.1. Самостоятельное изучение документации VK API для ботов

Цель работы: углубиться в документацию VK API, чтобы понимать все возможности создания ботов и быть готовым к самостоятельной разработке.

Задания для выполнения:

  • Перейдите в раздел VK API Bots: Начало работы.
  • Внимательно изучите разделы о типах событий (входящие сообщения, нажатия на кнопки, вступления в сообщество).
  • Познакомьтесь с методами отправки сообщений и клавиатур (кнопки для интерактива).
  • Узнайте, как использовать Callback API и Long Poll — выберите, какой способ вам кажется более удобным для вашего будущего проекта.
  • Посмотрите примеры кода на официальных языках (Python, PHP, JavaScript).

Результат: вы будете иметь структурированное понимание VK Bot API и сможете приступить к практической разработке.

3.2. Эксперименты с созданием агента в Yandex Agent Atelier

Цель работы: создать и протестировать ИИ-агента в визуальной среде Yandex Agent Atelier, освоив базовые принципы конфигурации.

Пошаговые эксперименты:

  1. Создайте простого агента без инструментов: задайте ему роль "Консультанта по продуктам" и составьте подробную инструкцию.
  2. Добавьте базу знаний: загрузите небольшой файл с информацией о продуктах (или создайте простой текстовый документ) и подключите его к агенту через Vector Store.
  3. Добавьте простой инструмент: реализуйте инструмент для расчета скидки (например, по коду купона).
  4. Проведите диалог: последовательно задавайте агенту вопросы, наблюдая, как он использует базу знаний и инструменты.
  5. Проанализируйте логи: посмотрите, как агент рассуждает и какие шаги предпринимает для ответа.

Результат: практический опыт работы с платформой, понимание процесса создания агентов и их возможностей.

3.3. Проектирование сценариев для чат-бота или агента

Цель работы: научиться проектировать пользовательские сценарии (диалоговые потоки) для чат-бота или агента, чтобы обеспечить высокое качество обслуживания.

Задания для выполнения:

  1. Выберите задачу: например, "Запись на прием", "Подбор товара" или "Получение справки".
  2. Составьте карту диалога: нарисуйте блок-схему или таблицу, отражающую все возможные пути диалога (вопросы → ответы → действия).
  3. Определите сущности: какие данные нужно собрать у пользователя (имя, дата, номер заказа)?
  4. Продумайте обработку ошибок: что делать, если пользователь ввел что-то непонятное или запросил то, что бот не умеет?
  5. Создайте промпт для LLM: на основе карты диалога напишите подробную инструкцию для модели, которая будет лежать в основе агента.

Результат: готовый, детализированный сценарий, который можно использовать для быстрой разработки чат-бота или настройки агента на любой платформе.

Резюме: хороший сценарий — это основа успешного диалогового интерфейса. Тщательное проектирование окупается высокой пользовательской удовлетворенностью и эффективностью автоматизации.
