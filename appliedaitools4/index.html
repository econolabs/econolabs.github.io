Практика 4

Практика ИИ: Запуск на домашнем компьютере

Пошаговое руководство по настройке окружения формата «Copy-Paste-Run» без использования облака

Шаг 1: Python

Для работы понадобится установленный язык программирования Python (версии 3.9–3.12).

Объем загрузки: ~25 МБ
Важно: при установке на Windows обязательно отметьте галочку "Add Python to PATH".
Шаг 2: Библиотеки

Откройте терминал (Командную строку / PowerShell) и выполните команду оптимизированной установки библиотек:

pip install torch torchvision --index-url https://pytorch.org requests Pillow
Объем загрузки:
• torch + torchvision (CPU): ~180 МБ
• requests + Pillow: ~5 МБ
Итого: ~185 МБ
Флаг --index-url ... /cpu отсекает тяжелые компоненты CUDA, экономя до 2.5 ГБ трафика.
Шаг 3: Старт ИИ

Создайте на компьютере файл ai_test.py, вставьте в него учебный код на PyTorch и запустите через терминал:

python ai_test.py
Динамическая загрузка при первом старте:
• Вес модели MobileNet_V3: ~9.8 МБ (скачивается автоматически один раз)
• Тестовое изображение: ~100 КБ
