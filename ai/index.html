Тема 1. Психология инноваций и принятие ИИ

1.1 Типовые реакции психики на инновации

Внедрение искусственного интеллекта в образовательный процесс часто встречает сопротивление. Это нормальная защитная реакция психики на изменение привычного уклада. Понимание этих стадий помогает преподавателю и администрации выстроить грамотную стратегию внедрения.

Стадия Проявление Что делать
Отрицание «Это не для нас», «ИИ — это игрушка», «У меня и так всё работает» Показать конкретные примеры экономии времени (проверка тестов, генерация заданий)
Агрессия «ИИ отупляет студентов», «Это приведёт к деградации образования» Признать опасения, перевести в конструктивное русло: обсудить границы применения
Торг «Хорошо, я попробую, но только для одной темы» Поддержать инициативу, дать простой инструмент с быстрым результатом
Принятие Преподаватель сам ищет новые способы применения ИИ Поощрять, делиться опытом внутри коллектива
Важно: сопротивление часто связано не с технологией как таковой, а со страхом потери контроля и статуса эксперта. Подчёркивайте, что ИИ — это инструмент, а не замена преподавателя.

1.2 Как преодолеть сопротивление

Ключевой принцип — начать с малого и показать быструю выгоду.

Практические шаги
  • Автоматизация рутины: предложите использовать ИИ для генерации вариантов тестов или проверки однотипных задач.
  • Прозрачность: покажите, как именно работает модель, где она ошибается и как это проверить.
  • Обучение в действии: проведите короткий воркшоп, где преподаватели сами запустят простую модель на своём ноутбуке.
  • Сообщество: создайте чат или методическое объединение, где можно делиться опытом и задавать вопросы без страха выглядеть некомпетентным.

Тема 2. Запуск нейросетей локально

2.1 Программы для запуска: Ollama, llama.cpp и другие

Для работы с нейросетями без передачи данных в облако можно запустить модель прямо на своём компьютере. Это особенно важно для образовательных учреждений, где есть требования к конфиденциальности.

Инструмент Сложность Особенности Для кого
Ollama Низкая Одна команда для запуска, автоматическая загрузка моделей, кроссплатформенность (Windows, macOS, Linux) Преподаватели, начинающие пользователи
llama.cpp Средняя Максимальная производительность на CPU, тонкая настройка параметров, требует компиляции или готовых бинарников Технически подготовленные пользователи
LM Studio Низкая Графический интерфейс, встроенный каталог моделей, удобный чат Те, кто предпочитает визуальные инструменты
Пример запуска в Ollama

После установки Ollama откройте терминал и введите:

ollama run llama3.2

Модель скачается автоматически и запустится в интерактивном режиме. Для остановки введите /bye.

2.2 Требования к компьютеру

Требования зависят от размера модели (количество параметров). Чем больше параметров, тем больше нужно оперативной памяти.

Размер модели Примеры ОЗУ (минимум) VRAM (для GPU)
1–3 млрд параметров Phi-3, Gemma 2B 8 ГБ 4 ГБ (опционально)
7–8 млрд параметров Llama 3.1 8B, Mistral 7B 16 ГБ 8 ГБ
13–14 млрд параметров Llama 3 13B, Qwen 14B 32 ГБ 12–16 ГБ
30+ млрд параметров Mixtral 8x7B, Command R 64 ГБ 24 ГБ и выше
Практическая рекомендация: для учебного кабинета с обычными ПК (16 ГБ ОЗУ) оптимально использовать модели на 7–8 млрд параметров в квантованном формате (Q4). Они работают приемлемо быстро и дают качественные ответы для большинства образовательных задач.
Что такое квантование? Это сжатие модели, при котором веса хранятся с меньшей точностью. Модель занимает меньше памяти и работает быстрее, но может немного терять в качестве. Формат Q4_K_M — хороший баланс для повседневного использования.

Тема 3. Где брать нейросети: Hugging Face

3.1 Структура и функции платформы

Hugging Face — крупнейшая платформа для обмена моделями машинного обучения, которую часто называют «GitHub для ИИ» [citation:1][citation:5]. Здесь публикуют свои модели исследовательские лаборатории и сообщество.

Основные разделы Hugging Face:
  • Models — репозитории с весами моделей. Можно скачать модель и запустить локально.
  • Datasets — наборы данных для обучения и дообучения моделей.
  • Spaces — демонстрационные приложения, которые можно запустить прямо в браузере без установки [citation:5].

Для доступа к некоторым моделям (например, Llama от Meta) требуется регистрация и принятие лицензии.

3.2 Модели, датасеты и Spaces

Раздел Что внутри Как использовать преподавателю
Models Сотни тысяч моделей: текстовые, графические, для распознавания речи Найти модель, скачать и запустить локально через Ollama или LM Studio
Spaces Готовые веб-приложения на базе моделей (демо, генераторы, анализаторы) Использовать сразу в браузере без установки — удобно для демонстрации на занятии
Datasets Размеченные данные для обучения и тестирования Использовать для студенческих проектов по обучению простых моделей

Рост количества моделей на Hugging Face (условная динамика)

Платформа растёт экспоненциально. Если в 2022 году счёт шёл на сотни, то к 2025 году — на миллионы.

Как это использовать
  • Для преподавателя важно не «объять необъятное», а найти 2–3 проверенные модели под свои задачи.
  • Начните с раздела Spaces — там уже есть готовые демо, которые можно показать студентам.
  • Для локального запуска ищите модели с меткой GGUF — они предназначены для llama.cpp и Ollama.

Тема 4. Разработка собственного блога

4.1 GitVerse, GitHub Pages и аналоги

Для публикации методических материалов, домашних заданий и примеров можно использовать бесплатные платформы статического хостинга, работающие напрямую из Git-репозитория.

Платформа Особенности Подходит для
GitHub Pages Бесплатный хостинг статических сайтов прямо из репозитория. Поддерживает Jekyll, Markdown, кастомные домены [citation:3][citation:11]. Блог, портфолио, документация проекта
GitVerse Российская платформа с Git-репозиториями, CI/CD, AI-ассистентом GigaCode и облачной средой GigaIDE Cloud [citation:2]. Проекты с требованием размещения данных на территории РФ
GitLab Pages Аналог GitHub Pages с поддержкой CI/CD из коробки. Проекты, где уже используется GitLab
Как создать блог на GitHub Pages (кратко)
  1. Создайте репозиторий с именем username.github.io (где username — ваш логин).
  2. Добавьте файл index.md или index.html с содержимым.
  3. В настройках репозитория (Settings → Pages) выберите ветку main и папку / (root).
  4. Через несколько минут сайт будет доступен по адресу https://username.github.io.
Совет: для блога с регулярными публикациями удобно использовать генератор статических сайтов (Jekyll, Hugo). GitHub Pages автоматически собирает Jekyll-сайты из Markdown-файлов [citation:7].

Тема 5. Виды тестовых заданий

5.1 Классификация тестовых заданий

При разработке тестов для контроля знаний студентов важно использовать разные типы заданий — это снижает вероятность угадывания и позволяет проверить разные уровни усвоения материала .

Тип задания Что проверяет Плюсы Минусы
Выбор одного / нескольких ответов Знание фактов, узнавание правильного варианта Быстрота проверки, охват большого объёма материала Высокий процент угадывания, механическое запоминание
Открытый ответ (краткий) Умение воспроизвести формулировку, применить знание в знакомой ситуации Исключает угадывание, проще в разработке Сложнее автоматизировать проверку (нужны точные эталоны)
Установление последовательности Понимание порядка действий, алгоритмов, процессов Проверяет логику, а не только память Требует тщательной проработки дистракторов
Установление соответствия Связи между понятиями, классификация, алгоритмические умения Хорошо проверяет системность знаний Занимает больше места на экране, сложнее в вёрстке
Рекомендация: для итогового контроля сочетайте типы заданий. Например, 60% — выбор ответа (быстрый охват), 20% — открытый ответ (глубина), 20% — на соответствие и последовательность (системность).
✅ Что важно запомнить
  • Сопротивление ИИ — нормальная стадия. Работайте через малые шаги и быстрые победы.
  • Ollama — самый простой способ запустить нейросеть локально. Для моделей 7–8B достаточно 16 ГБ ОЗУ.
  • Hugging Face — основной источник моделей. Начинайте с раздела Spaces для демонстраций.
  • GitHub Pages / GitVerse — бесплатный хостинг для блога или методических материалов.
  • Тестовые задания должны быть разнотипными: это повышает надёжность контроля.
